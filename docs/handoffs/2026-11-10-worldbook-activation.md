# 9000 世界书：不因扩展兼容提示禁用整条设定

基线 `74ea6ceb3839b1b7e0fdeb099f9a610c358d476c`。用户要求去掉截图中的限制，导入条目可用，触发逻辑继续参考酒馆。

## 改动

- 移除 `worldEntryWarnings` 导致的整条跳过；导入审核只默认保留原文件关闭的条目，不因未知扩展选项默认关闭已启用条目。
- 额外字段开关按酒馆的追加扫描语义处理：人设、角色描述、性格、角色深度提示、场景、作者备注，兼容 camelCase 与嵌入卡 snake_case。缺失字段按空内容，不成为额外必需条件。扫描深度 0 不扫描额外字段；常驻条目仍可生效。
- 正式生成和预览共同使用存档中的可用角色身份／能力及开场场景；不捏造尚未提供的角色卡字段，也不把隐藏内心或服务器私有卡全文暴露到前端。
- 支持正则关键词、生成类型过滤、角色／标签过滤、忽略单书预算；本轮总字数预算仍保留。常驻、关键词、次要条件、概率、递归、包含组和作用范围仍控制是否触发，不把所有导入条目变成常驻。
- 正则关键词扫描在独立 Worker 中运行，支持取消与超时终止；异常不回退到主线程执行。生成发送前再次核对存档、所选轮次／分支及实际 API 绑定，迟到扫描结果不用于旧请求。
- 尚未完整支持的扩展提示保留，但不再一刀切禁用整条。专用插入位置没有对应容器时，命中内容暂放到角色定义后并提示，导出保留原位置。
- 无新增持久化字段或数据库，未知字段仍在既有 `extra` JSON 中保留，备份格式不变。

## 验证

- 前端 144 文件、820 项通过；后端 450 项通过、4 项跳过；类型检查及生产构建通过。
- 独立 Edge + 本机合成模型：两种生成顺序各推进 4 轮。带额外角色扫描开关的正则关键词条目进入实际正文请求；原本关闭和未命中条目不进入请求；终端历史继续实时可见。
- 真实浏览器 Worker：复杂正则超时后主页面心跳继续（测试中约 151 次）；取消后可再次扫描。
- 真实生成入口：扫描超时和取消后输入保留、任务释放；修改输入后可重新生成。未调用真实付费模型。
- 真实 IndexedDB：本地下载、文件导入、云端格式采集与覆盖、覆盖前副本恢复，世界书选项与绑定、预设开关与顺序和终端记录一致；云端不含 API Key。并非真实 GitHub／Gitee 文件上传测试。
- 模拟线程测试验证超时与取消；已有 API、慢请求、保存失败和并发配置／备份测试一并执行。本机证据在既有 `.integration/worldbook-compat-*`。

## 发布与边界

本次发布为 9000 前端热更新，保留旧哈希资源，避免重启与中断已有请求；不更新 8807、8088 或服务器内置书的运行进程。旧版本已关闭的条目不会被擅自重新开启，可手动开启或重新导入原文件。

这不是完整酒馆扩展运行时。粘滞／冷却／延迟、世界书向量触发、自动化脚本和高级宏尚未完整实现；仅保留扩展设置并提示，常驻／关键词基础逻辑仍生效。Creator Notes 等没有来源的字段保持空值。专用作者注／示例／Outlet 容器尚未实现。后续需分别实现，不能把“没有整条禁用”写成“所有扩展语义已完全兼容”。
