# 聊天正则与论坛来源定位

2026-10-18。

聊天顶栏增加“16 正则”。点击展开下拉面板，支持规则开关、新建、编辑、删除、导入、导出及替换测试；点击外部或按 Escape 收起。开关立即保存，编辑点击“保存正则”。规则按预设保存、切换、复制、删除和备份恢复。

## 预设兼容

支持读取 `extensions.regex_scripts` 与 `extensions.SPreset.RegexBinding.regexes`，相同规则去重，保留禁用状态。也支持单独酒馆正则对象、规则数组与含正则的完整预设文件。

过去已导入的预设不含当时被忽略的规则，无法凭空恢复；在正则面板选择“导入正则”，选原预设 JSON，即可只提取规则，不重复导入整套提示词。

实现 slash 正则与 flags、普通表达式、顺序替换、数字／命名捕获组、`{{match}}`、trimStrings、placement、仅显示／仅提示词、minDepth/maxDepth 和 runOnEdit。查找宏替换支持 `{{user}}`、`{{char}}` 原文或正则转义。宏式替换不是完整酒馆宏运行时。不要把“支持正则字段”误认为所有插件功能都已移植。

用户消息与 AI 正文可作显示替换；下一次请求的用户输入、剧情历史和客户端世界书插入支持提示词替换。显示替换不修改原始正文，提示词替换仅修改请求副本。记忆、已提交状态、模型原始控制块与服务器私有提示词不交给显示正则改写，避免损坏 MVU 解析。命令输出与推理字段 placement 保留配置，当前不执行。未设置“仅显示／仅提示词”的普通替换会用于显示及发送副本；不永久改写原文，与酒馆直接改原消息的持久行为不同。

## HTML 与运行隔离

原始回复或正则替换产生的 ` ```html ` 代码块、完整 HTML 页面和 HTML 片段均可渲染。支持 CSS、图片、表格、折叠、内联 JavaScript、事件处理器；正文与多个 HTML 代码块混排时保留前后文本。采用 `sandbox="allow-scripts"` 的独立页面，未授予同源、父页面存储、表单提交或顶层导航权限。

美化容器随内容自动增高和收缩，不再固定 340px。内置本地 jQuery 3.7.1 与 Lodash 4.18.1，许可证随文件保留；网络断开也能使用这两个库。HTTPS 外部脚本、样式、字体和图片按浏览器策略加载；网络资源失效仍可能影响第三方模板。

所有美化共用主题继承：默认画布底色、正文颜色和深浅模式取自所在页面，而非操作系统偏好。页面主题变化时同步刷新；预设后续显式声明的背景或文字颜色继续按 CSS 层叠生效。此机制不按预设名称做判断，不改写用户导入的正则或原始文本。

提供当前楼层的只读 `getVariables/getAllVariables`、`Mvu.getMvuData/getCurrentMvuData/getMvuVariable`、消息 ID、常用变量事件和 `waitGlobalInitialized` 兼容入口。不开放写存档、模型调用、密钥、父页面 DOM、任意网络请求或整个酒馆插件环境；依赖这些专属能力的脚本仍需适配，不能声称兼容所有插件。正文中 HTML 的脚本不会调用额外模型。脚本错误可展开查看，也可查看原文，原始楼层不被美化改写。

只读渲染数据为该楼层已验证的状态。服务器仅向隔离来源开放两个公开库的 GET/HEAD；业务 API 和其他路径继续要求同源。iframe 高度消息验证发送窗口与随机通道，变量数据嵌入时转义脚本结束标签。

正则仍在独立 Web Worker 内执行，1.5 秒超时终止并保留原文；替换结果长度受限。禁用规则可立即恢复原文。

实现参考本机 JS-Slash-Runner 的 iframe、依赖注入与高度调整思路，渲染器独立实现，未复制其受 PolyForm NonCommercial 许可约束的源码。参考仓库：https://gitlab.com/novi028/JS-Slash-Runner 。

## 论坛来源

点击“来源剧情”继续按来源楼层分页定位并滚动。对应正文出现淡蓝色下划线，约 3.5 秒淡出；重复点击重新计时。使用 HTML 正则时，隔离内容也接收临时下划线样式。

## 检查

领域测试覆盖导入格式、作用域、捕获组、深度、编辑标记、越界结果、错误回退与备份。工作区测试覆盖规则随预设复制、删除和保存。浏览器使用真实《双人成行》预设验证导入，再以合成 HTML 规则验证开关、隔离展示、编辑保存、刷新恢复和来源下划线，不调用用户模型。
