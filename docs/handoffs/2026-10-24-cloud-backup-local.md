# 云端备份：仅本地测试

用户明确要求本轮先本地测试，未经同意不得推送 main、发频道或部署/重启线上服务器。

本地地址 http://127.0.0.1:8807/terminal 。学院顶栏“设置”旁新增“云端备份”，工作区导航也有入口。Gitee / GitHub 各自配置仓库和临时令牌；令牌只在当前组件内存使用，离开后清除，不存浏览器、不入备份、不发模型。连接识别当前授权用户并创建或复用其私有仓库；公开同名仓库要求更名，保留其他文件。

备份页始终显示“保存当前备份”“上传备份”“拉取备份”。本地保存会落盘完整快照并下载 JSON，无需连接仓库。手动上传全部存档至 stellar-backups/全部数据备份.json，同名文件更新。每份 8 MB，超限报错而不截取数据。保留全部存档的剧情、人设、变量、记忆、终端记录、全部预设、世界书及界面设置；排除 API 配置、密钥、本地图片数据和 blob 链接；图片仅保留 HTTP/HTTPS URL。昵称头像 URL 独立于模型提示词保存。用户立绘/头像档案库不参与上传。

拉取先校验并预览存档总数，再确认覆盖全部存档及设置。现有 API 设置、密钥、人物媒体库保留。覆盖时在一个 IndexedDB 事务内写入恢复前快照与新内容，冲突或失败不替换内存；整个工作区保留一个上次覆盖前副本，可在备份页恢复。云端不含本地终端头像时保留现有头像。

新增测试包括两平台建仓/复用、私有仓库限制、文件路径和格式校验、API 会话和同源保护、备份图片/接口排除、原子恢复及多页面冲突。独立 Edge 的 UI 测试使用模拟平台响应，验证 360 / 414 / 1200 像素可见界面、上传、覆盖、全部存档替换、保留本地头像、本地恢复。没有用真实凭据创建仓库或上传真实存档，需用户填入自己的令牌进行实际平台验证。

2026-10-24 更新：CloudBackupView 调用 src/domain/cloudTransport.mjs，浏览器直接 fetch GitHub/Gitee（mode:cors, credentials:omit），不再调用 /api/cloud-backup，也无中转回退。令牌仅当前组件内存；Gitee 写入表单带 access_token，令牌不进入 URL/存档。共享适配器使用 TextEncoder/TextDecoder/atob/btoa，无 Buffer/User-Agent。应用解析上限 20 MB，不代表平台上限。独立 Edge 实际跨域调用两平台 /user（无真实令牌）均可读取 401 响应，另外以模拟平台 API 完成两平台直连上传、覆盖、拉取和本地恢复；未使用用户凭据做真实仓库写入。

后续界面调整：全宽无卡片边框；操作行与平台行使用独立 flex 行和 14px 间距；按钮统一米棕色；说明集中在标题旁问号弹窗。已移除云端生成、恢复解析以及通用 parseBackup 的旧 20 MB 限制，超过 20 MB 的测试备份已验证生成、读取和 IndexedDB 往返。GitHub 按官方文件接口 100 MB 处理；Gitee 没有猜测固定额度，由平台当前账号/接口实际限制决定。前端仍直连，无服务器回退。
