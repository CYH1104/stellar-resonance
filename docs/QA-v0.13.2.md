# v0.13.2 简洁 API 设置

日期：2026-10-16（Asia/Shanghai）。上一版验证记录见 QA-v0.13.1.md。

按用户指定布局重排：主API问号只在点击后挂载DialogShell说明；每个表单名称、URL、Key三列，模型默认下拉，获取模型、测试连接同行，保存API单按钮。手填模型保留为小入口，获取失败时自动展开。生成采样参数不在API卡片展示，原有值保留，剧情参数仍在预设页。测试耗时和安全错误反馈保留，正常状态不展示长篇说明；实际调用说明放问号中。

副API列表使用单一下拉框，一次挂载一份编辑器，切换或删除会卸载并取消该卡片的测活／获取模型任务。增加按钮只建立未加入配置的本地草稿，打开同格式弹窗；取消／退出删除临时凭据，不添加配置。点击保存校验通过后才创建配置并确认，失败移除临时新增项并保留弹窗供修改；成功选中新项并清理草稿。删除先确认，沿用既有移除逻辑恢复功能路由。主API必填、副API可选、向量开启才必填的约束不变。功能分工和本机Key保存选项折叠，保留实际模型及输出长度查看入口。

向量攻略缩为两句话：硅基流动注册链接、新建密钥入口、免费BAAI/bge-m3、付费Pro/BAAI/bge-m3、基础URL及Key填写。2026-10-16核对官方价目表 https://siliconflow.cn/pricing ，前者免费、后者收费；创建密钥及URL核对官方快速入门 https://api-docs.siliconflow.cn/docs/userguide/quickstart 。没有执行注册、创建密钥或真实付费调用。
