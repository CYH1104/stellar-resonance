# v0.16.0 论坛回复兼容及可调整布局

日期：2026-10-16。上一版见 QA-v0.15.0.md。

论坛反馈循环：node --test tests/forum-reply.test.mjs。新增普通文字及常用字段用例时，原解析器复现INVALID_FORUM_REPLY_RESULT，一项失败；修改后通过。原实现仅接收单字段content JSON，与模型直接回复的正常文字不兼容。现在接收普通文字、带或不带尾部换行的围栏、content/reply/text/message.content和JSON字符串。只提取正文；已知作者元数据忽略，作者仍由服务器给定。未知控制字段、状态协议、空回复、截断或坏JSON仍拒绝，显式思考继续过滤。未取得用户那次原始模型响应，因此不能确定当次具体是哪一种格式。

重复提示由网关错误文案与工作区再次追加“你的评论已保留”造成；网关改为单独描述问题，工作区检查后仅补一次。新增获取AI回复按钮，复用已有user评论ID，只发送到该评论为止的上下文，不重复新增评论；已有AI回复不重复请求，关闭功能后不请求。沿用接口取消、存档及来源动态校验，无自动追加付费重试。

布局采用受限数值偏好Preferences.layout，进入现有IndexedDB与备份；旧版缺失时默认空布局，损坏或未知尺寸丢弃/限制，不阻塞旧存档。外栏宽度保留正文最小空间，窄屏临时适配不改原值。每张左侧人物卡和四个小剧场按稳定ID保存宽高；拖动及方向键通过独立ResizeHandle更新，面板内滚动，窗口/组件关闭后无全局指针监听残留。顶部恢复默认布局重置尺寸；手机保持原单栏入口。

验证：116项Vitest、98项Node测试，共214项通过；类型检查及生产构建通过。覆盖论坛解析复现红转绿、真实HTTP普通文字/别名/截断路由、重复错误去重、原评论重试及回复去重、关闭不请求、卡片及侧栏边界、SSR手柄、布局自动保存与重开/备份恢复，以及原功能回归。未读取真实Key、未进行真实模型调用、浏览器点击或视觉验收（此前浏览器访问限制仍遵守）。本轮仅本机更新，未追加上传GitHub。
