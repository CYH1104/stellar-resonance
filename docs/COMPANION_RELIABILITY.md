# 状态与小剧场保留修复

2026-10-18。采纳诊断文档中已核对源码的缺陷，不禁用预设 HTML 美化，不新增自动模型请求。

- 前端允许传递已知 STATE 诊断码；仍过滤原文、凭据和任意未知内容。格式失败同时显示已知字段错误原因。
- 单次响应内，状态封装与独立 theater 块中的剧场按 slot 汇总；有效完整场景不会被同槽空场景覆盖。
- 手动补全保留本轮已成功的槽位，新增结果补充缺失槽位。合并后重新核对缺失剧场提示，不清除其他状态警告。
- 应用 `<done>` 仅表示应用协议标记，不再立即取消上游读取。等待上游 finish_reason、DONE 或响应结束；保留超时、取消及响应体大小限制。只有同一次请求，没有为此自动续写或补修。
- 新生成的回复保存 stateEnabled 和四个剧场配置快照。健康检查按该轮配置评估；旧存档没有快照时继续兼容原有行为，不猜测历史开关。快照随浏览器存档与备份保存。
- “有效变量已更新”与“待补全／沿用旧值”分开显示；不将局部校验接受描述为业务字段全部完整。

验证包含：混合封装、空重复槽位、提前结束标记后续有效 SSE、上游结束但 socket 不关闭、手动补全未返回旧槽、备份往返配置快照、安全诊断及字段级错误文案。浏览器回归继续检查预设正则导入、显示开关、HTML 隔离渲染和编辑持久化。

模型完全漏写的内容不会凭空补出。尚未定位的上游断流与特定预设宿主交互空白仍需分别诊断；此修复不宣称它们已全部解决。
