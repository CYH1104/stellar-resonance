# 操作提示与局部 HTML

提示类反馈统一使用 `DismissibleNotice`，或在操作中调用 `showNotice(message, error)`。全站仅由 `NoticeHost` 绘制，样式及计时在一处维护。成功、失败均 8 秒隐藏，支持手动收起；同一条相同级别的提示去重，最多同时显示 3 条并排列，避免相互覆盖。

测试中的进度保留在操作区域内，等待用户确认的对话框及持久的配置状态不属于临时提示。记忆条目上的错误详情也保留在条目内供后续排查，不使用悬浮提示的样式。

正文支持以下局部样式；外层普通正文继续使用原排版：

```html
<div style="color:lightblue;padding:12px;border:1px solid currentColor">
  局部样式内容
</div>
```

支持相邻的 `<style>` 与 HTML 块，以及 HTML 代码围栏。每个独立片段在隔离 iframe 中展示，样式不影响父页面。继续沿用只读变量桥及沙箱限制，不开放父页面存储或状态写入。未闭合片段保持文字回退，不在流式接收时提前执行半截 HTML。系统状态、论坛及小剧场标签仍由原有协议处理，不作为正文 HTML 使用。
