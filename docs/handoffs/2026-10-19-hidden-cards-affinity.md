# 卡片隐藏与每轮好感对应

- 卡片空字段及旧“未提供”占位显示为“未知”。作者设定仍受保护，提示词要求根据世界书、人设和当轮正文填写有依据的新角色事实。
- 新 NPC 默认建立数值好感0；旧在场 NPC 缺少好感时在状态归一化阶段初始化0并保留缺失判断提示。已有数值不重置。
- 每张在场卡片要求同 ID 的当轮态度判断；漏项以 STATE_ATTITUDE_REVIEW_MISSING 提示，可手动补全。不强制每轮增长。变量折叠栏展示每个实际评估角色的前后值，包含中性的0变化；名单绑定当前稿件并持久化。
- 在场卡片展开后可点“隐藏此角色卡片”，仅影响侧边栏。Session.hiddenActorCardIds 按存档保存并支持导出导入；不改变在场名单、变量、世界书或模型提示词。
- 顶栏17“隐藏角色卡片”打开弹窗，勾选可恢复单个卡片，也可全部恢复。已离场的隐藏角色也可解除隐藏，下次在场时显示。

验证：服务端254项、前端345项测试及类型检查通过，生产构建通过。独立本地浏览器验收“未知”显示、隐藏后移除、刷新保持、顶栏17弹窗恢复；未调用模型。私有截图 .integration/hidden-cards-ui.png。
