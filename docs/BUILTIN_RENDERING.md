# 内置显示模式

按 2026-10-18 的最新选择，剧情正文和预设结构使用内置组件，不再执行预设 HTML、美化脚本或 iframe。导入的规则仍可编辑、导出；显示侧跳过 HTML 注入，删除、文本替换和提示词侧规则保留。br/b/i/em/strong 这类简单标记允许经过规则，但最终仍走内置文本显示。

HTML 注释及明确的隐藏标签在服务端和前端过滤，流式未闭合时也隐藏。不会增加模型调用，不展示或存储专门的草稿审计抽屉。小剧场、行动选项和普通 details 转为可滚动折叠卡；glass_status 为只读状态展示，不猜测覆盖真实 MVU；现有结构化 JSON/MVU 更新机制保持原样。未知标签作为不可执行文字保留，脚本、样式、iframe 内容丢弃。原始存档正文不因显示转换被删除。

正则继续在可终止 Worker 中执行，不降级到主线程。任意第三方复杂模板的字段映射、将预设摘要自动写入记忆、完整酒馆助手运行时，不在本次实现范围。

预设采样参数中的最大输出支持手动输入整数 1–32000，以及 1600、2048、4096、8192、16384、32000 的快捷填充。随当前预设保存；不会自动提高。实际可用输出仍取决于上游模型限制。
