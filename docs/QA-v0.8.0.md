# v0.8.0 本机保存 API 配置

日期：2026-10-15。

新增浏览器专用 api-credentials 记录，默认记住 Key。位于原 IndexedDB 数据库的 workspace 存储，独立于 snapshot；数据库不升级、不清空旧存档。普通 read/backup/export 只访问 snapshot，凭据记录使用独立读写和白名单校验，不放进 Profile、Session、Snapshot 或预设文件。关闭记住后持久记录中 keys/confirmed 置空；清除全部也清空页面内存。自动保存与显式保存共用写入队列，清除后的旧任务不覆盖新状态；失败显示失败，不宣称保存／删除成功。

重开后恢复主／副／向量 Key、路由、向量开关，仅对此前确认且当前地址／模型匹配的档案重新登记本机后台，不调用 models 或生成接口。更改地址、模型或 Key 仍使确认失效；旧版没有本机凭据时仍需首次填写。API 凭据读取失败时停用记住，避免默默覆盖旧记录，用户可以显式清除或重新启用。

测试覆盖实际 IndexedDB 新实例读取、凭据与聊天存档分离、关闭后删除、额外字段过滤、危险地址拒绝；工作区覆盖三种 Key 的重开恢复、自动登记且无外部调用、关闭后的页面继续可用但重开不恢复、清除后自动保存不复活、地址变化不自动确认、写入失败不报告成功。全部使用合成 Key，不读取用户真实 Key、不发付费请求。

此前本地浏览器读取被策略拒绝，本轮未绕过；自动检查覆盖存储和工作区调用，视觉仍由用户试用。

最终结果：59项前端／存储／工作区测试与37项服务器／模型适配测试，共96项通过；类型检查、生产构建通过。本机 v0.8.0 已按正常网络权限启动，health 确认版本；模型列表传输诊断使用无效测试凭据得到预期认证拒绝，未发起付费生成。
