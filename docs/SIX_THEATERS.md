# 六个小剧场

论坛固定为 slot 1，不占小剧场数量；slot 2–7 为六个小剧场，其中原群聊 slot 2 继续使用悬浮手机，其他位置为侧栏折叠卡。

默认开关保持原样：论坛、群聊开启；同人文、自定义及新增的 slot 5–7 关闭。旧四槽设置迁移时保留所有原设置，只补关闭的新位置。用户自行决定开启数量；新增位置支持自定义、同人文、群聊消息，日记等通过模板配置。

服务端沿用同一轮的输出协议，按实际开启槽位动态生成示例；扩容不增加模型调用。关闭的槽位不发送专属指令及小剧场历史。校验、保存、补全与回读支持 slot 7，超过六份或重复槽位仍拒绝。缺失或无效内容沿用已有兼容处理，不丢弃有效槽位。

预设页和剧情错误提示加入：如果正文显示异常，请检查预设中是否仍开启了美化、小剧场等条目；可尝试关闭后重试。

小剧场设置显示当前开启数量，并提示按需调整预设输出上限；不会自动更改上限。
