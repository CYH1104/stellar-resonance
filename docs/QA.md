# v0.11.2 存档删除

日期：2026-10-16（Asia/Shanghai）。上一版验证记录见 QA-v0.11.1.md。

继续游戏和存档与导出两处共用 SaveList，均提供逐份删除入口。弹窗显示目标存档名称、玩家、轮数与删除范围，取消和关闭不会执行删除。确认后使用原快照写入队列删除对应 session；先等待本地事务成功，再移除内存列表，失败保留原记录并显示可重试错误。操作只修改工作区快照，不写入或擦除独立的 API 凭据记录。

删除当前存档会清除当前选中ID、未发送输入并返回存档页；删除待打开目标会清除该目标，避免稍后确认 API 后打开不存在存档。生成、记忆索引、人设辅助或新建存档过程中禁用删除。删除期间借用 busy 锁定相关操作；其他保存等待删除完整结束后再捕获快照，避免旧列表重新写回。无需配置或调用模型才能删除。已经导出的备份文件不会修改。

新增4项工作区行为测试覆盖：删除含聊天和带向量记忆的目标后重新载入不复现，保留其他存档／预设／API配置与凭据；删除当前与最后一份存档及任务进行中拒绝；写入失败不改变内存或原持久快照、不误报成功并可重试；删除期间并行保存不会复活存档、无需配置API删除待打开目标。

本轮最终验证：77项前端／工作区／SSR组件测试通过，类型检查及生产构建通过。服务器接口行为未改动，仅同步版本号。预览按正常网络权限重启且仍只监听127.0.0.1，health确认为v0.11.2，首页200，地址 http://127.0.0.1:5173/。

所有删除测试使用合成存档；未删除用户真实数据，未读取真实Key或调用付费模型。未绕过此前浏览器访问限制，因此未进行实际浏览器点击或视觉验证。
