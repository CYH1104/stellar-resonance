# Mahjong tile artwork

Author: FluffyStuff. Source: https://github.com/FluffyStuff/riichi-mahjong-tiles

The 40 SVG files are unmodified copies of Regular/*.svg. Each file was verified against its Git blob SHA-1 at the pinned commit. Original suit glyphs are transparent artwork; the application displays them on Front.svg, and Back.svg for concealed tiles. Haku.svg is intentionally blank. Images are bundled by Vite and served from this application, with no external image requests. The original PNG preview is not shipped.
