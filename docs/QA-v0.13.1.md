# v0.13.1 生成反馈与模型测活

日期：2026-10-16（Asia/Shanghai）。上一版记录见 QA-v0.13.0.md。

用户报告各模型均无正文但中转站有输出。未读取用户Key、浏览器数据库或实际回复，无法断言其具体请求原因。代码核查及合成响应回归确认两个缺陷：共享思考过滤器会让旧未闭合块吞掉新续写块后的正文；原读取器忽略 finish_reason，中转站保持连接且不发送 DONE 时持续等待。新增回归分别覆盖旧块延续和新响应重新开块；隐藏内容不回传为续写上下文、不显示或记录。补修状态使用独立过滤器。

读取器支持标准SSE结束、finish_reason结束、SSE中完整message、无type文字块、最后一条事件缺少双空行和JSON响应。结束通知只结束单次HTTP读取，不跳过游戏完成标记和状态校验。响应体读取也服从取消和超时。只有推理／未闭合思考标签／隐藏或空白内容／空回复给出静态具体错误，无可用正文时不自动追加三次调用；正文已存在的截断仍最多续写三次。状态补修与续写预算不变。未知错误体和密钥不直接显示。

生成页面增加阶段、总耗时、输入区旁错误；安全阶段事件不含模型原文或推理。设置显示剧情实际模型和经预设覆盖的Token上限。

新增POST /api/probe，要求已有同源本机会话，支持未登记的API配置；只验证URL／模型／Key，文本发送固定短提示且上限512输出Token，向量编码固定单条文本。60秒超时，客户端取消会中止后端请求。返回耗时和可见字符数量或向量维度，不返回文本／向量／上游错误体，不加载私有卡、用户人设、剧情、记忆或预设，不保存Key或测活结果。主、副、向量每张卡独立按钮；配置改变／组件销毁取消旧任务，旧结果无法覆盖新配置。测活成功不自动确认API，不修改功能路由或存档。界面说明可能计费及测活不等于完整剧情验收。

验证：91项Vitest（含SSR），85项Node模型／服务器测试，共176项通过；vue-tsc类型检查、Vite生产构建通过。覆盖保持打开的SSE、关闭前abort、兼容响应形状、三种无正文失败、跨续写思考过滤、状态修复、探测文字／向量成功、鉴权／网络／推理失败、不传私有上下文、无确认测活和路由不变，及入口／阶段／错误SSR渲染。未使用真实Key调用付费模型，未做实际浏览器点击或视觉验收（此前浏览器访问策略限制仍遵守）。实际中转站请求需要用户刷新后主动测活及重试确认。
