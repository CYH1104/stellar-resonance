- **第二份聊天保存失败**：第一份聊天已写入，第二份注入 503 后没有写入，确认恢复过程也存在部分提交窗口。restorePending 中断标记和覆盖前完整副本仍保留。释放锁并新建 repository 后，使用保留副本恢复，两份原生 JSONL 均与恢复前一致，中断标记随后清除。这验证了底层副本可恢复，不等于原页面的一键恢复已经通过。
- **客户端恢复锁过期**：实际聊天保存后将客户端时钟推进 125 秒，完成校验拒绝，副本和中断标记保留。失败的 settings 队列会阻挡第一次解锁；显式 settings.reload 后才可释放本次锁，新建 repository 后能恢复原聊天。本项模拟客户端过期判断，未覆盖真实服务器心跳或续租网络失败。
- **过期页面写入**：两个独立客户端读取同一版本，第一方写入后，第二方提交旧版本被拒绝，且拒绝发生在任何聊天写入之前；第三方读取确认较新文本保留。本场景跨页面保护通过。
