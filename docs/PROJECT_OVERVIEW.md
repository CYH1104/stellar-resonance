# 项目概览

《群星共振》已有星际 ABO 群像人设与背景，目标是将它们组织成可互动、可保存进度的游戏。正式资料由作者提供，仓库中的测试资料使用虚构内容。

## 已确定方向

2026-10-14 已确认改为响应式网页优先。Vue 3 + TypeScript + Vite 构建网页，Cloudflare Workers + D1 处理身份、存档、世界书、规则和模型网关。手机与电脑通过浏览器访问。

玩家可设置自己的 Key、模型、基础预设与 User 人设。完整作者资料与隐藏规则保留在服务端，按玩家状态筛选最少必要的上下文。网页和安装包如果使用相同后端，保密边界相近；网页的优势主要是发布、更新和内测便利。

## 阶段目标

MVP：少量测试角色与测试账号走通登录、自填 Key、流式聊天、变量和存档恢复，并完成手机与电脑验收。先邀请 2～5 名朋友使用受控预览环境。
Alpha：完善正式群像角色、ABO 状态、关系、NPC 独立记忆、事件、高级预设与正则。
Beta：地图背包、10～50 人模拟负载、更多兼容项及是否需要 EXE / APK 的评估。

网页 MVP 不要求完整 SillyTavern 或任意助手插件运行环境。客户端加密、完全离线保密和多账号额度切换不属于当前实现方向。

## 实现前需要确定

- 官方 API 与指定中转站的准确白名单、模型与上游日志可见性。
- 内测玩家身份与邀请机制，以及作者导入入口认证方式。
- 测试角色和第一批世界书材料，正式 ABO 变量与解锁规则。
- Cloudflare 账号、发布入口和预算，以及团队任务认领。

这些决定在对应 Issue 中记录。缺少决定时可以开发虚构 fixture 和 mock 网关，正式接入与对外内测须使用已确认的配置。
