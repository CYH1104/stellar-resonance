# 剧情游戏邀请与观战

2026-11-27。新增功能仅9000，8807保持现有稳定版本。

## 使用方式

正文中角色明确想玩或发起斗地主、日麻、六人狼人杀、十点半、大话骰、真心话大冒险时，随本轮终端通讯请求生成游戏邀约。终端桌面显示「朋友的游戏邀约」，玩家可参加、进入观战位或婉拒。相同来源不重复生成，否定、假设或过去事件不触发。

角色使用已知角色ID组成完整牌桌。玩家参加时，邀请卡已标明的最后一位替补让座；观战时全部由角色入座，玩家不占席位。不为凑人数创建陌生人。未接受邀请不会自动消耗游戏API；进入后点击开始观战/继续推进。不在关闭页面后无限后台生成，也不补造不存在的历史对局。

斗地主和日麻在当前牌桌自动出牌，可以暂停、退出后继续。其他游戏复用已有阶段推进。历史小局可在观战页选择回看，查看历史时暂停当前自动出牌；桌面「角色对局记录」可重新进入已保存的房间。

## 知情与记忆

- 观战组件仅接收公开投影，不接收牌堆、角色暗牌、隐藏骰子或策略参数。日麻只公开牌河、副露和规则允许结算亮出的牌。
- 狼人杀观战全程不展示角色身份、狼队密谈、女巫药物和预言家查验；死亡、公开发言和公开结果可见。游戏结束也不公开身份。
- NPC请求继续经各游戏服务端校验，精确匹配参与者与请求角色；狼人互认使用原有私有视角，其他角色不获得全局身份表。
- 角色记住实际参与者、剧情时间和已确认结果。玩家在观战位时明确标注「玩家仅观战」，没有假装参与或醉后独处小剧场。
- 邀请绑定已确认正文的锚点、回合输入指纹；回退到其他剧情分支时邀请与对应房间隐藏。
