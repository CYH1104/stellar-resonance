# 人设编辑与模型选择

人设编辑支持“人设表单模式”和“人设表单自定义模式”。自定义模式保留姓名、第一性别、第二性别、精神力等级、精神体、身份这六项状态栏字段，异能和其余设定在同一个大输入框编辑，不再单独分栏。已有结构化字段会合并展示；首次编辑大输入框后统一保存为原文人设。切回表单可在“原文人设”继续编辑，不会丢弃文本，也不会自动拆解自由文本覆盖结构化字段。完整人设继续发送给剧情模型。

人设字段及私人备忘录取消单字段字符限制，所有文本框自动换行并随内容和宽度变化调整高度。备忘录保持私人用途，不发送给模型。文件导入仍有 256KB 文件大小检查，接口整体请求大小和模型上下文容量仍由原有传输配置及服务商决定。

API 地址和 Key 填好后自动获取模型列表，修改配置会取消旧请求并延迟合并刷新。支持大小写不敏感搜索、手动刷新、去重，取消手填模型名。已有选择保留，空选择首次获取成功时选择列表第一项；获取失败不会覆盖已保存的模型。

验证：前端 362 项、服务端 306 项通过；类型检查和生产构建通过。浏览器使用合成接口检查自动获取、搜索、配置变更刷新、模式切换内容保留及输入框增高，不调用真实计费模型。
