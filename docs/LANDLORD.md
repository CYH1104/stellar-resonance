# 三人斗地主

## 入口与牌桌

游戏室新增斗地主，邀请恰好两位好友，三家同意后开局。复用现有好友邀请、留言、氛围预设、用户/角色头像及房间历史。用户点牌选中，再点出牌；提示只选合法牌，不代替用户出牌。两家均不出后恢复上一出牌者领牌。

未结算牌局进入终端横版布局；窄竖视口内用CSS旋转终端，宽视口直接展开。只改变终端视图，不强制改变手机系统方向，不要求全屏权限。结算、返回房间、关闭/隐藏终端均移除横版；恢复该局时按阶段重新计算。横版禁止拖窗，恢复后保留原窗口行为。离开牌桌暂停NPC自动推进，保留已保存的手牌与积分，可继续；主动结束是单独操作。

## 规则及积分

标准单副54张：17张×3、3张底牌。3至A、2、小王、大王依序增大，不比花色。采用0/1/2/3叫分制，只能叫更高分或不叫；3分立即定地主，三家不叫则本局不计分、下一局重新发牌。首版不含癞子、明牌及平台额外加倍玩法。

支持单、对、三张、三带一/对、顺子、连对、飞机及单/对翼、四带二/两对、炸弹和火箭。顺子/连对/飞机机身不得含2和王。单翼可用对子拆作两张，不能复用机身；对翼须不同点数对子；双王不作组合翅膀。炸弹压普通牌，火箭压炸弹，其他同类型且同长度比主点。

每个新房间每家10000分，下一局继承当前余额。底分100×叫分×倍数，每个炸弹/火箭及春天/反春天各翻倍。地主双份、农民各一份；任意农民出完即农民方胜。地主胜且农民无人出过牌为春天，农民胜且地主只出过一手为反春天。

输家不足支付时封顶至当前余额，不产生负数；地主不足时两农民平分已支付额，奇数余1按座位给第一名农民。全部三家的积分总和始终30000。比分及结算由程序单次提交，重试不重发牌或重复转分。

只有积分归零者才把本房间酒量设为该人的酒量上限，自动结束房间并进入分角色醉后小剧场；不按每局输赢另加酒。先算完所有积分，再处理全部破产者。主动结束不扣未结算积分、不生成小剧场；已经完成的破产结算不因离开界面撤销。小剧场失败仅重试该篇，不重复结算。

## 性格与信息隔离

初次开局由终端模型读取服务器角色资料，给两名NPC配置1～5的牌技、主动性、配合度和简短牌风说明，同时只补缺失酒量。谨慎不自动等于高手，好胜不等于低智；无牌技资料时默认中等并参考观察/分析经验。配置保存在房间内，不每手重算。

实际出牌由本地启发式策略执行：牌技影响组合保留、公开记牌和报单拦截；主动性影响叫分、抢出牌权和炸弹时机；配合度影响农民给队友让牌。策略只接收该NPC自己的手牌、公共底牌/出牌、各家张数和积分，不接收整桌隐藏手牌。记牌只对公开牌与本人手牌做保守上界推断，不给未知牌指定持有人。此版不是职业赛训练模型。

局内出牌无需逐手请求模型；玩家主动发送桌上聊天时，模型只见公开动作、计分和最近公开台词，不发暗牌。动作是程序事实，不编造固定角色台词。公开聊天沿用随机多句与少量沉默机制，不能推进出牌或改积分。
