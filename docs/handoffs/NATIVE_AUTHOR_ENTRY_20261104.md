# 8088 新版作者入口接入

2026-11-04，基于迁移分支 `7a1c5be`。用户要求将作者后台接入新版；本轮实现和部署入口 `/editor/`，不代理旧 8808，也不写旧 8807／9000 的资料。

## 可用入口与权限

- 新版作者后台：`http://43.138.251.91:8088/editor/`。未登录时转到新版管理员登录页，成功后返回作者页；普通账号返回 403。管理员在学院账号控件中也可点击“作者后台”。
- 登录、退出、账号列表、启用／停用与改密码使用未修改的原生账号路由。账号、密码、邀请码均属于新版独立实例；旧作者独立管理密钥不会自动成为新版账号密码。
- 原作者主界面的 HTML、CSS、编辑模块和世界书字段模块继续使用原文件；仅在新版响应中注入账号控件、标注新版和调整原生顺序说明。原作者 UI、原 editor store、原版 SillyTavern 跟踪源码未修改。
- 账号管理页对接原生账号机制，提供用户查询、启停、管理员设置新密码、邀请码批量签发、批次统计与未使用码撤销。重置密码后原会话按原生账号版本失效，不使用旧 SQLite 用户库或另造登录态。
- 私有编辑接口在原生插件中再次校验管理员。所有写操作继续经过原生 CSRF；作者请求也绑定打开页面的账号，切换账号后停止旧页请求。作者页面保持同源脚本策略和禁止嵌入，控件样式改为独立 CSS，HTTP 场景补 UUID 支持。

## 资料写入和生效

作者资料仍位于服务器 `/var/lib/stellar-native-academy/author-assets`。使用现有 `createEditorStore` 的字段校验、修订号冲突检查、上次文件副本和临时文件重命名保存。角色卡、隐藏世界书、地图与地点、初始开场和内部功能规则接入此目录。

保存成功即更新新版 catalog 和 tasks 的资料投影，不重启服务、不删除正在处理的任务。已创建的正文／辅助任务及终端任务持有创建时的作者资料快照，编排准备阶段使用该快照；后续任务使用新资料。终端复核沿用原快照。功能规则覆盖通过请求作用域应用，防止不同请求互相混用。地图读取修正为实际保存的 `editor.map`。

作者界面不再显示旧版消息图并声称是原生实际请求：仅展示可编辑的学院功能规则，注明最终消息顺序由原生预设和编排决定。本轮不声称完成 v2.1 世界书／助手迁移，不安装服务器浏览器，不解除 `ACADEMY_PUBLIC_PREVIEW=1` 或启动编排服务。

## 数据与备份兼容

- 玩家存档、JSONL、swipes、人设、备注、备忘录、草稿、终端记录及 BackupArchive 字段未改动，不新建 localStorage 或 IndexedDB。
- 作者文件仍用现有 version 1 格式及原校验器；写入前检查原修订号，未知版本或无效字段停止保存。
- 邀请记录继续用原生 `_storage` 中 `academy-invite:<sha256>`、version 1；新增可选 `batch`、`note`，旧记录按空字符串读取，注册仍只接受 unused 状态的一次性码。列表不返回原码或哈希，撤销与注册共用串行队列。
- 学院私有作者设定及账号认证管理元数据不进入玩家本地下载、云端上传／拉取或覆盖前恢复副本；这些仍走现有统一玩家备份。部署前整实例副本同时包含 `data` 与 `author-assets`，包含原生认证与作者资料。API／仓库密钥、本地图片等既有排除规则未改变。
