# v0.11.1 玩家精神体 OS

日期：2026-10-16（Asia/Shanghai）。上一版记录见 QA-v0.11.0.md。

定位：提示词把 player.spiritThought 写成可选字段，结果校验也接受遗漏、空字符串或“未提供”，前端再显示统一“未提供”占位。精神体种类是人设，OS 是 AI 随剧情生成的动态反应；user 本人的内心想法仍不生成。

回归测试先复现：玩家已填写精神体但模型遗漏 OS，旧校验仍成功。修复后每轮提示要求非空中文 OS，后台拒绝遗漏、空白和常见缺资料占位，返回 PLAYER_SPIRIT_THOUGHT_MISSING，保留正文且不提交本轮状态，不用静态随机文案冒充模型内容，也不在读取旧存档时偷偷调用付费模型。未设置精神体时不擅自生成其 OS。

界面把玩家精神体 OS 的缺省提示改为“等待 AI 随剧情生成”，缺少精神体种类则提示在人设填写。旧“未提供”占位同样按等待处理。旧存档初始状态缺少精神体但 persona 已有时，恢复种类用于显示。实际模型结果通过状态块返回，按有效回合更新；回退恢复此前 OS。人设与玩家状态标签统一为“身份（院系/职业）”。

验证：73项前端／工作区／SSR组件测试、63项服务器／模型适配测试，共136项通过；类型检查与生产构建通过。新增覆盖提示词要求、模型遗漏／空白／占位拒绝、真实HTTP处理路径上的OS传递、未知精神体不生成OS、SSR等待／更新／回退与旧存档种类恢复。本机预览已用正常网络权限重启，health确认为v0.11.1，首页200，地址 http://127.0.0.1:5173/。

未读取用户真实Key、未调用真实付费模型，未绕过浏览器读取限制；真实模型生成的语气与剧情适配仍需用户游玩确认。原历史缺失的 OS 不追溯编写；下一轮完整回复或手动续写成功后即可更新。
