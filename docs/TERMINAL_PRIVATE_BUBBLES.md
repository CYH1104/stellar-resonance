# 终端私聊段落气泡

角色私聊的一份回复按空行（兼容 Windows CRLF 和只含空格/制表符的空行）分成多个独立消息气泡，单换行保留在气泡内。玩家消息和群聊不拆分。旧消息无需迁移即可显示。

实现仅在分页之后投影显示：不修改 TerminalMessage、存储ID、原文、历史上下文、重试判断、未读数量及备份格式；同一原消息的所有段落留在同一页。没有增加 API 请求，也不另发逐段请求。

验证：分段/元数据/原记录不变/玩家和群聊/分页回归，以及终端聊天相关测试共24项通过；vue-tsc及生产构建通过。

当前用户发布指示（2026-11-17）：仅更新9000；8807和8088保持现有进程及快照。此指示优先于旧的双端默认约定。部署使用明确的单实例 test/9000 参数，并前后核对8807 PID及快照不变。
