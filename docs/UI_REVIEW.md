# 原终端批注调整

- 主卡片进入当前或最近更新的对话；没有存档则进入新建人物表单。加载本机存档期间的点击会排队，避免误判为空。没有配置模型时先引导设置，不自动调用模型。
- 左栏采用竖线、圆点、编号与文字，移除编号方框及重复入口。“学生档案”改为“人物档案”；左上入口改为“设置人设档案”。
- API、预设与设置移到右上角关闭键旁；开屏颜色及日夜切换控件隐藏。
- 全部功能仅列出九个已实现入口，移除脚本宿主相关的采集、指令、控制面板与随机事件入口。功能页全屏显示；设置、记忆等不再夹在对话侧栏中。
- 首页图片改为独立的绝对定位底图层，默认宽度65%，不参与右侧功能卡片的布局。移除常驻滑条；从“全部功能 → 调整立绘大小”进入编辑，拖动图片移动、拖四角等比缩放，支持保存、取消、重置与更换图片。保存的归一化位置和宽度在刷新后恢复。右侧卡片恢复原布局宽度，底图放大不会挤压它们。
- 左侧导航贴近屏幕边缘，行前标记为实心小方块，保留文字与编号。
- 编年史去掉卡片和图片边框；可导入、替换和移除图片，保留原图比例并受可用宽度约束。图片以 Blob 存入独立 IndexedDB；不发送给 AI，不进入游戏存档导出。单张最多10MB。
- 地图沿用原页面结构，颜色变量及字体与学院统一。
- 开屏数据流轻微缓慢闪动；标题上停留两只鸽子，进入时一只飞离，另一只留在原处。减少动态效果设置下立即进入。

新增样式与交互由 `terminal-enhancements.css` 和 `terminal-enhancements.js` 维护，构建前通过 `scripts/sync-terminal.mjs` 同步到原 HTML。浏览器验证使用独立临时配置和虚构测试存档，没有调用真实模型。
