# 玩家姓名与头像排版

基线2b90044。用户要求姓名放到头像上方，修复大头像旁姓名被垂直居中的不合理布局。

- 玩家消息header改为两列网格：姓名在右列第一行居中、头像在右列第二行居中，整体靠右；骰点留在左列。隐藏头像时姓名保留，不留空头像行。
- 长姓名可换行，限制宽度，避免挤压头像。仅修改CSS，不改玩家数据、头像构图或请求。
- 生产构建通过。使用生产样式和真实UserAvatar组件验证大号竖向、中号圆形、小号方形和隐藏头像四种情况，DOM几何检查确认姓名在头像上方、中心对齐、整体靠右、姓名可见；320px宽容器显示正常。没有为这次纯排版变更新增单元测试。
