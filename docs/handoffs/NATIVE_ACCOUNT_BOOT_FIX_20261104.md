# 8088 原生账号入口与启动修复

2026-11-04。基于迁移分支 `661a2f6`，仅涉及独立新版。旧 8807、9000 与旧作者入口 `/editor/` 保持原服务。8088 仍未提供完整作者管理页，不能声称旧作者后台已迁移。

## 发现与处理

- 原生登录页没有学院邀请码注册入口；原账号退出控件在加载遮罩下无法操作。新增学院样式的登录／邀请码注册页，调用原生登录、退出和 CSRF；当前账号与退出控件在加载期间亦可操作。管理员账号可生成新版一次性邀请码。
- 未确认真实不同账号之间发生过服务器串档。但同浏览器切换账号后，旧页面继续用更新后的 Cookie 提交资料，存在写入新账号的风险。学院请求和原生 SDK 请求绑定打开页面时的账号；网关以当前原生会话核对，拒绝不一致的请求。退出／重新登录广播使旧页停止请求，保留旧页输入；未另建聊天或用户数据库。
- 邀请码注册扩展挂在原生 public router，仍经过原生 CSRF、会话处理。账号创建委托未修改的原生 `/users/create` 路由，输入固定 `admin:false`；不接受客户端提供的管理员标志、目录或已有账号覆盖。邀请码先预留后创建，失败不自动重新开放；已有账号不能在登录状态下注册覆盖。
- 原生引擎冷加载有大量静态模块请求，旧网关逐次关闭上游连接。新增独立 HTTP 连接池、逐请求 Cookie 传递、hop header 清理。仅静态 GET 和明确定义的只读 POST 在响应头发送前允许一次连接错误重试；写入、生成不重放。取消和流错误正常传递，不追加伪成功响应。
- 启动注入模块异常显式报告初始化失败，等待文案改为中性加载说明；未改变官方模块或其入口顺序。此前公网冷登录约 37.7 秒、普通刷新约 19.9 秒，不能据此声称启动已即时完成。

## 数据、权限与兼容

账号仍使用原生 node-persist 用户资料、原生密码哈希、原生用户目录、JSONL、settings 和 Secrets。邀请记录在同一原生 `_storage` 中使用 `academy-invite:<sha256>` 命名空间，保存版本、签发人、状态、领取账号和使用日期；原始邀请码仅生成时返回给管理员。不增加浏览器 localStorage、IndexedDB 或存档字段。

邀请信息属于账号认证管理数据，不进入玩家 BackupArchive、本地剧情下载、云端上传／拉取和覆盖前恢复文件。用户人设、主人设、备注、备忘录、草稿、终端记录及原生附加资料的现有完整备份入口、旧格式解析、ID 重绑与密钥／图片排除规则未改动。部署前另作整实例数据目录副本，该副本包含原生认证元数据。

本次不启用私有生成编排，不安装服务器浏览器，不移除 `ACADEMY_PUBLIC_PREVIEW=1`。正文、人设辅助、终端等调用仍可能明确返回 `NATIVE_PRIVATE_COMPILER_PENDING` / 503；这是原有部署暂停，不能冒充上游密钥故障，也不能宣称真实模型调用已验收。
