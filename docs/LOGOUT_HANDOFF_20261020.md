# 退出登录交接

原代码已有角落退出按钮及后端登出接口，本次补齐清晰入口和退出后重新登录的行为。

- 首页功能菜单、“全部功能”和固定账号栏均提供“退出登录”。一次点击向服务器提交 POST `/api/auth/logout`，成功后 replace 到 `/login`；失败保留当前页面并允许重试。
- 服务端撤销当前账号登录令牌、删除当前游戏会话，同时过期账号及游戏会话两个 HttpOnly Cookie。重放旧 Cookie 不能访问受保护页面或接口；重新登录后也不能沿用退出前的游戏会话，需要 bootstrap 创建新会话。
- 同浏览器其他标签页收到账号范围的退出通知立即返回登录页；恢复焦点、切回标签、浏览器返回缓存页时复核服务器登录状态。缓存页面在恢复校验前隐藏，校验不可用时返回登录页。
- 不删除存档、人设、预设或本机配置，不退出其他设备的独立登录会话。不把账号密码或 API Key 写入通知。

当前 `127.0.0.1:8817` 为 AUTH_REQUIRED=0 的免登录开发预览，没有账号登录态，因此不显示账号退出入口。启用账号认证的正式服务才有登录/退出行为；本次没有擅自改变本机账号模式或迁移存档。正式部署前后端按共享 main 一起更新。

验证：账号接口真实HTTP测试覆盖撤销、双Cookie过期、重放失败、重新登录、旧游戏会话失效及其他账号不受影响；客户端脚本测试覆盖3个入口、失败重试、存档保留、多标签和缓存恢复。完整服务端测试通过；前端Vue源码及构建产物本次未改变。
