# 终端消息和好友申请

已知角色主动私聊不再要求先成为好友，消息直接进入通讯列表，不自动接受或创建好友关系。角色可随正文主动发出好友申请，玩家自行决定是否接受。

添加好友支持终端码或存档角色姓名。重名时选择具体角色；通过姓名添加不需要暴露或虚构终端码。2026-11-21 修复：发送申请使用 API 设置中明确选中的终端接口（主 API 或副 API），与私聊和游戏一致。所选接口缺失时提示，不回退到其他接口。此条取代下文历史验证中的副 API 专用约定。

自动私聊、群聊和角色主动申请仍随正文的一次响应同步。已有群资料被模型重复输出且发生漂移时保留存档内资料，继续同步合法消息；未知角色或无效私聊单独诊断，避免丢失其余群聊。

## 自由添加联系人

添加页分为终端码添加与姓名／关系添加。姓名查找先复用已有角色；重名需选择。未找到时可直接把姓名或关系描述作为联系对象，例如自己的哥哥、路人姓名，填写留言后由副 API 一次生成联系人的姓名、身份、关系及接受／拒绝回应。新联系人获得稳定独立 ID，存于当前存档 terminal.contacts，随 JSON 导入导出保存，后续终端聊天带入身份关系；不直接改写正文人物表或捏造终端码。未加好友的既有私聊可以直接回复，群聊邀请与游戏仍沿用已有机制。

验证：前端 494 项通过；后端 345 项通过、4 项跳过；类型检查通过。新增覆盖自由联系人的副 API 调用、保存还原、后续聊天身份、非法生成结果拒绝，以及新联系人不会破坏正文终端上下文。
