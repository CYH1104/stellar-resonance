# 用户终端头像导入

基于 a084f86。用户反馈头像文件选择后没有显示，并要求单个“导入文件”按钮。原生文件框改为隐藏 input，由按钮打开；处理中或正文生成期间禁用，选择后重置 input，可重复选择同一文件。

原解码只使用 createImageBitmap；新增浏览器 Image／object URL 回退，处理 API 缺失或解码失败。接受浏览器声明的图片及无 MIME 的常见图片扩展名，实际以解码成功为准；保留 5MB、2400万像素限制，压缩最长边400px，校验输出 data URL 后才提交头像与默认构图。释放 bitmap／object URL，失败不写入头像；系统无法解码的图片显示转换格式提示，不承诺所有 HEIC 均可读取。

11 项头像／终端显示回归和类型检查通过，覆盖 bitmap 失败时回退、空 MIME、缩小、导出再导入、错误时释放资源。未使用用户实际原图，未做实体手机实测，因此不能确定用户原故障是否恰好为该解码路径。

另按用户要求检查内置提示词及服务器 editor-data、extracted-pro，没有发现其报告的外世界人名或学校关键词；用户随后明确不要新增设定约束，已完全撤回临时 World consistency 规则及其测试，不在本次发布修改提示词。
