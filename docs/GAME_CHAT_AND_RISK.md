# 游戏连续聊天与性格风险决策

## 现有十一点半规则（本轮不改判胜）

牌型：五花牌 > 五张不过 > 十一点半 > 普通牌 > 爆牌。同类普通牌/五张不过比较总点，同为十一点半依次比较黑桃、红桃、梅花、方片张数，完全相同按庄家/座次优先。所有人爆牌均为最低牌型，不比较爆了多少点，因此庄家优先。本规则是本项目现有约定，不声称各地区通用。

新增elevenWinnerReason只说明既有结果，compareHands和结算、连庄、罚酒不改。结算界面和规则处明确显示全爆/普通同点的庄优先原因，避免误以为模型临时判输赢。

## 连续对话

国王游戏、十一点半、真心话大冒险、大话骰共用GameChat，以“姓名：内容”按已保存的先后显示。删除十一点半的波次标题；不按说话人归并，不在刷新时重新洗牌。状态、牌面、题卡、命令与惩罚仍是独立游戏信息，不伪装成角色内心台词。

每次请求由服务器生成dialogueSchedule.slots：普通闲聊角色约4%本次无发言，通常1条，有时2～3条；随后随机打乱槽位。必须执行命令/回答题目的主要角色仍需完成核心任务；静默不省略必须的choice/refused/penalty等结果。保证至少有1个发言槽位。不额外请求模型来洗顺序或补齐沉默角色。

新模型格式以dialogue数组返回槽位台词，同一ID可重复；解析严格匹配服务器槽位，不能插入玩家、未入席者或任意新角色。模型只输出说出口的话，不写思考、内心独白或旁白。旧的每角色一条结果仍支持；必要的命令结果和罚酒仍用原唯一ID结构，台词条数不会增加罚酒次数。

## 可见信息与风险

十一点半传入实际执行后的公开牌张数/停牌状态、公开聊天与用户留言，用于不确定地猜测对方强弱。自己的真实牌用于本人决策；别人的暗牌和私有区段不能当成已知信息，玩家手牌不发送。原批量模型能看到NPC资料区段，属于单模型多角色逻辑范围约束，不能声称物理隔离。所有NPC的服务器性格/描述/世界书用于扮演，保守、爱冒险、好胜等可以在相同8点时选择不同策略。

大话骰保持每次只发送当前行动NPC自己的五颗骰子，依据公开叫号和台词猜测真假。公开台词可以试探、诈唬、半真半假，但不能把猜测写成确定事实。模型不返回内心推理。程序继续控制随机发牌/摇骰、点数与输赢，语言输出不能改结果。

## 存档与兼容

GameDialogue {version:1,lines}标记现代重复/乱序/缺席发言。XI wave/batch、骰子move和普通游戏聊天的dialogueVersion区分旧严格格式与新格式，旧记录不被悄悄放宽或重写。现代静默表示回应已完成，不被误判成pending而卡住；每名活跃NPC的私有决定依然完整合法。

真心话分别保存choiceDialogue与dialogue，保留选题及回答时的对话；普通游戏互动只追加一次玩家真实输入，再追加原序NPC消息，不把玩家输入嵌入每个人文本。国王游戏round/interaction可选dialogue保留多条台词，核心replies继续用于效果幂等。全部字段随原终端存档进入本地/云端/分片/覆盖前恢复副本；未知版本、身份或异常长度在写入前拒绝。
