# 群星共振 · 存档删除 v0.11.2

## 朋友试玩：从 GitHub 下载后怎么打开

1. 在本次试玩分支选择 **Code → Download ZIP**，解压整个文件夹；不要只下载一个 HTML。
2. 电脑安装 **Node.js 24.12 或更新版**（含 npm）。第一次双击 **首次准备并启动.bat**，它会联网安装依赖、构建网页，然后打开浏览器。后续双击 **启动预览.bat** 即可。
3. 在网页“设置”填写自己的主 API 地址、模型名和 Key，确认配置后新建游戏。向量 API 和副 API 按需配置。
4. 此分享版默认载入 `server/example/feature-demo.json` 的虚构测试世界，可测试聊天、人物状态、精神体 OS、骰子事件、四个小剧场、预设、长程记忆、自动续写和存档管理。实际 AI 功能由自己的模型服务提供，可能计费。

GitHub 保存源码；当前版本在下载者自己的电脑运行。你的 `127.0.0.1` 链接不能给朋友远程访问，也未开通公网部署。聊天、存档和 Key 使用各自浏览器的本地存储，不会随代码下载获得你的数据。

作者的原始隐藏人设／世界资料未提交。维护者本机若已有 `server/private/extracted-pro.json`，仍优先使用它；缺少该文件才使用示例。示例也由 Node 后台读取，前端不新增世界书编辑器。

非 Windows 用户在项目目录运行 `npm install --ignore-scripts --package-lock=false`、`npm run build`、`npm start`，再打开终端给出的本机地址。开发者仍可使用锁文件对应的 `pnpm install --frozen-lockfile`。

“继续游戏”和“存档与导出”的列表均可逐份删除存档。弹窗核对名称、玩家和轮数，确认后才写入本地；失败保留存档并允许重试。删除包含该存档聊天、状态、记忆向量、骰点和小剧场；其他存档、全局设置与 API Key 保留，已经导出的备份文件不受影响。无需先配置 API，也不发起外部请求；生成或索引进行时不可删除。删除当前存档会返回列表，删除最后一份显示空列表。

玩家填写精神体种类后，其 OS 由 AI 根据每轮剧情生成，无须玩家事先提供。模型提示与结果校验均要求每轮返回非空的 player.spiritThought；漏写或“未提供”等占位结果会明确报错并保留正文，状态不提交。尚未收到生成结果时显示“等待 AI 随剧情生成”；精神体种类未设置时提示补填，旧存档不会自动产生虚构 OS，下一轮完整回复或手动续写可更新。user 本人的内心想法仍不生成或显示。

模型必须在正文和完整状态块后输出隐藏结束标记 `<SR_DONE>`。服务器拦截所有状态与结束标记；普通流结束、finish_reason 或仅有状态块不算完成。缺少完整结束时，从断点自动追加最多3次模型请求，界面显示进度，可随时停止；仍未完成才提示并提供“继续续写”。续写复用原行动、骰点和剧情接口，不创建新回合。仅最终完整合法的状态提交一次；未完成正文持续本地保存，不触发摘要或建议。自动续写也可能产生供应商费用。

开启骰子后，新行动投一次D100：1～5大凶、6～35不利（负面事件），36～65平平（中性插曲），66～94顺遂、95～100大吉（积极事件）。后台将方向写入本轮必需剧情规则，要求正文落实具体后果并返回 diceEvent。事件缺少或方向相反属于内容校验失败，保留正文为未完成稿，不提交新状态；不会自动重演来纠正。完整稿旁显示骰子事件反馈，并将后果保存在记录与事件记忆中。关闭后新行动不额外投掷；重试／重演／续写沿用原骰点。

user 卡只显示姓名、第一性别、第二性别、身份、精神体、精神体 OS 和已遇到 char 的好感度，不显示 user 内心想法。身份可在人设及设置填写，可按已发生的剧情更新。相遇依据当前分支的完整有效主线在场记录；离场后仍保留，切稿／回退同步重算，提名或论坛发言不算。缺好感度规则仍显示未提供，不补零。

主 API 必填，副 API 完全可选。设置页为剧情、记忆摘要、行动建议、AI 帮我写人设分别提供下拉列表，默认全部主 API。只有主 API 也能使用全部文字功能；未选用的副 API 可留空或保留草稿，不影响进入。人物状态、论坛和小剧场属于同一轮剧情回复，跟随剧情接口；向量检索继续使用独立的向量 API。

默认开启“在此浏览器保存 API Key”。主／副／向量 API 的 Key 独立存入 IndexedDB 本机凭据记录，不进入聊天存档、备份、预设导出、Cookie 或服务器配置。确认后重新打开网页，会恢复地址、模型、分工、Key 和已确认接口；只向本机后台重新登记地址，不请求外部模型。可关闭记住 Key（删除持久记录、当前页面仍可用），或清除本机全部 Key（同时清除当前页面 Key）。

旧版从未保存到本地的 Key 需要在升级后填写并确认一次，之后自动恢复。浏览器／网址端口不同不共享存储，清理网站数据或无痕窗口关闭后需要重新填写。

本版修复预设 role:model 的导入：自动转换为 assistant 并提示转换条数，保留全部条目与开关。已只读核对“夏瑾 天琴座 Beta 3.82.json”，144条全部通过导入、备份恢复和导出再导入；原文件不改动。

可添加多个副 API；各功能只按下拉列表选择调用，不再自动使用第一个副 API。移除正在使用的副 API 后，相关功能回到主 API。仅主 API、被功能选用的副 API，以及开启检索时的向量 API 要求完整并确认。

新的开始、继续存档、返回剧情及发送行动都会检查必需配置：地址、模型、Key、参数和当前页面确认。修改地址／模型／Key 会要求重新确认；未完成时跳转设置并列出缺项，不会偷偷回退其他剧情接口。确认只登记本机连接，不发起模型生成，也不保证凭据或模型已通过真实测试。

向量设置旁内置“向量检索新手攻略”：硅基流动注册／认证、创建 Key、免费模型价格核对、具体栏位填写和本地索引步骤。2026-10-15 官方价目表的 BAAI/bge-m3、bge-large-zh-v1.5、bge-large-en-v1.5 标为免费，Pro/BAAI/bge-m3 为收费版本；实际价格和权限以平台为准。攻略带官方链接，不需要安装软件或运行命令。

向量使用兼容 embeddings 的 API；记忆页点击“生成缺失向量”建立本地索引。查询文本交给向量服务编码，结果在浏览器本地比较，检索失败会退回关键词。聊天、记忆、向量结果保存在 IndexedDB；向量服务会收到用于编码的记忆／查询文本。

修复大型酒馆预设被250条上限误拒的问题。导入不再限制250条或全部文字30万字，仍保留5MB文件大小限制；全部条目及开关、排序会保存。生成只提交当前启用、非占位、非空且符合触发时机的提示词，30万字上限只检查本轮实际启用文字。预设管理显示总数与已开启数。

已只读核对用户的 `小冰块V3.81.json`：374条，全部文字480975字，91条开关开启；验证导入、本地备份恢复、导出再导入均保留374条。普通回复实际消息组装含约3.5万字预设文字，原始文件未改动，未调用外部模型。可用 `node scripts/check-preset.mjs <预设路径>` 重做检查；只打印计数，不打印提示词正文。

模型与预设 → 填写 API 基础地址和本次 Key → 点击 **获取模型** → 在下拉列表选择 → 点击确认此 API。获取列表不要求预先填写模型名，使用兼容接口的 `/models` 元数据请求，不发送人设或聊天，也不会生成剧情。支持手动输入；服务不支持、返回空列表或获取失败时保留原模型名，不擅自改选。列表仅保留在当前设置页内存，修改地址／Key 会清空旧列表，Key 不写入存档。服务列表可见不代表每个模型都支持当前剧情协议。

## 本版变化

- user 状态卡只汇总已遇到 char 的对 user 好感度，包括后来离场的人物；好感规则未提供时仍显示未提供，不补成零。所有人物状态新增精神体与精神体 OS。精神体种类从原文明确字段读取，不使用人物外号；OS 是每轮允许更新的公开状态。
- 顶部“论坛小剧场”改为“小剧场设置”，中间不再重复右侧论坛。右侧最多4个窗口：论坛、群聊、两个可配置窗口。默认只开论坛和群聊。内置同人文、角色访谈、精神体日记、课后碎片和自定义模板。窄屏通过“查看小剧场”打开。
- 同人文的配对主角只允许 user 与一名 char。玩家人设新增配对偏好；BL 攻受、BG／GB 需要明确的第一性别和偏好，不依据 ABO 猜测。原插件没有角色第一性别的明确字段，因此资料不足时先显示待补充并写非亲密日常。小剧场搭档不会改变主线在场名单。
- 模型与预设 → 预设管理 → **导入酒馆预设文件**。导入后按条目启停、排序、展开编辑内容，设置角色、注入位置／深度和正常／重演触发。支持选择多份预设、导出当前预设；不必复制 JSON 手动修改。旧的三字段导入限制已删除。

小剧场与主线在同一次模型回复中返回，但保存在独立字段，不重复到正文或直接写入主线记忆；切稿、回退和备份跟随有效稿件。开启多个窗口会增加输出长度，输出上限太低时可能截断，可在模型设置调整。详情见 [预设兼容与小剧场规则](docs/PRESETS_AND_THEATERS.md)。

本项目是一张包含多名 NPC 的世界叙事卡。服务器保管人设和世界观，AI 推进剧情、判断当前在场人物，网页展示正文和校验后的状态。已删除玩家勾选在场角色的功能，也不再用原文摘录冒充一轮剧情。

## 本机试用

打开后先进入白底文字开场页，真实载入本机存档时显示加载文字，完成后可选 **新的开始、继续游戏、设置**。继续游戏打开存档列表；没有存档时该入口禁用。

新的开始进入人设表：姓名默认留空且必填，空格不计为姓名；表格新增 **精神体** 和 **其他**。下面的 **AI 帮我写** 可输入想玩的人设，使用“AI 帮我写人设”所选接口结合服务器世界观补全空白项，已填写内容保留。失败或取消不改表格，生成后可手动修改，点击开始游戏才会创建存档。切到模型设置再返回，当前草稿仍保留；草稿尚未创建存档，刷新页面不保留草稿。

1. 已有构建文件时，双击 **启动预览.bat** 启动本机后台并打开网页。首次从 GitHub 下载请先执行上面的准备步骤；需要 Node.js 24.12 或更新版本，已有预览脚本也会查找本机 Codex 自带的 Node。
2. 点击开场页 **设置**，填写主 API；按需添加副 API，并选择剧情使用哪个接口。填写实际 API 基础地址（一般为服务商提供的 `https://…/v1`）、实际模型名和 API Key。支持兼容 Chat Completions 的服务；本地模型允许本机 HTTP 地址。
3. 需要向量检索时先打开开关并填写向量 API。点击 **确认配置**，然后点击 **配置完成，继续**。确认仅登记地址；发送剧情时才会把服务器卡片和剧情交给选中的服务。
4. 点击 **返回开场 → 新的开始**，填写姓名、人设，或用 AI 帮我写。点击开始游戏后输入行动，例如“我拿着录取通知来到报到处，看看接下来怎么办。”
5. AI 输出剧情并决定谁在场，左侧状态随本轮结果更新；右侧论坛可按剧情产生虚构动态，不保证每轮发帖。
6. 关闭网页不停止后台；用 **停止本机测试.bat** 停止。

默认地址 `http://127.0.0.1:5173/`，端口被其他程序占用时选用 5174～5180 并打开对应网址。不同端口的浏览器存储不同，换端口前先导出备份。升级保留旧存档，但旧版演示／资料摘录存档仅供查看，请新建世界卡存档测试。

Key 按“在此浏览器保存 API Key”开关保存在本机；关闭时只在当前页面使用。随请求临时交给本机后台，不进入聊天存档、备份、Cookie 或后台配置。已保存且确认的接口在刷新后自动恢复；改动地址／模型／Key 后仍需确认。必需的 API 未填写并确认时不能进入剧情；不配置模型就无法生成正式剧情，没有假 AI 回退。当前没有附带可用的模型账号或 Key。

## 资料和状态

提取自用户提供的 pro 脚本：14 名角色、5 个院系、12 条地点／活动、原迎新文案和基本世界观。原脚本未执行；100 条事件素材仅归档，未启用随机事件池。完整世界书、初始在场名单和好感规则原文件未提供，没有补写。见 [提取记录](docs/EXTRACTION.md)。

原 `sex` 值 Alpha／Beta／Omega 映射为第二性别；第一性别不根据称呼或代词猜测。AI 可随剧情生成允许展示的 char 简短想法和精神体 OS，不能随意改固定人设；好感度规则未提供，目前服务器过滤掉模型的好感度变更。初始没有在场角色，等待 AI 建立第一幕。提到名字、回忆、远程通讯和论坛发帖都不自动等同于在场。

完整成功回合才提交状态。正文截断、传输中断或生成超时会在同一连接内自动续写，最多3次追加请求；每次独立计时。主动停止、续写用尽、未知角色或状态校验失败时，正文保留为未完成稿，沿用上一轮状态。可手动继续续写，也可重试、重演、切稿和回退。手动续写会复用当前未完成稿并从其正文断点接续，不重发此前隐藏状态。

## 数据位置与边界

```text
dist/                              网页公开文件
server/private/extracted-pro.json  私有角色与世界卡资料
server/ai.mjs                      模型上下文、流式正文和状态校验
src/domain/                       前后端共用的类型与状态规则
server/.local/                     本机运行记录和日志
```

浏览器只接收必要公开状态、剧情和选中的地点介绍；没有下载完整私有资料的静态接口。聊天、状态、记忆、论坛互动、骰点和非敏感配置保存在当前网站的 IndexedDB，不是 Cookie，不自动跨设备同步。记忆支持本地关键词和可选语义向量检索；向量服务只编码检索文本，向量结果保存在本地。

**本机测试 ZIP 包含服务器私有资料，仅供维护者使用。** 将来给朋友使用应提供部署后的网页地址。私有目录和运行日志已从 Git 跟踪中排除，不自动上传 GitHub。

当前仅监听本机，不是可公开的商业平台部署。公网版本需要朋友账号、HTTPS、限流、服务端固定模型地址和凭据。服务器存放能避免直接下载整份卡，但提示词约束不能保证模型绝不复述设定；所选模型服务会收到用于生成的私有设定。不要向不信任的服务发送资料。
