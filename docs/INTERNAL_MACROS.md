# 内置提示词的酒馆宏

内置 AI 提示词与用户预设使用同一个文本宏解析器。行为参考本机 SillyTavern 的 `macros/definitions/variable-macros.js`、`core-macros.js`、`env-macros.js` 和 `variables.js`，不是按某一份预设的写法定制。

目前支持：

| 写法 | 结果 |
| --- | --- |
| `{{user}}`、`{{char}}` | 当前玩家姓名、稳定的世界卡名称 |
| `{{persona}}` | 当前玩家人设文字 |
| `{{group}}`、`{{groupNotMuted}}`、`{{charIfNotGroup}}` | 本项目为单世界卡，返回世界卡名称 |
| `{{input}}`、`{{lastUserMessage}}` | 本轮用户输入 |
| `{{lastCharMessage}}`、`{{lastAssistantMessage}}` | 最近的 assistant 历史消息 |
| `{{lastMessage}}` | 最近的历史消息 |
| `{{setvar::名称::值}}`、`{{getvar::名称}}` | 设置、读取局部变量 |
| `{{addvar::名称::值}}` | 数值相加；非数值文本追加；数组变量追加元素 |
| `{{incvar::名称}}`、`{{decvar::名称}}` | 自增、自减，返回新值 |
| `{{hasvar::名称}}`、`{{varexists::名称}}` | 返回 `true` 或 `false` |
| `{{deletevar::名称}}`、`{{flushvar::名称}}` | 删除变量，无输出 |
| 上述变量名称中插入 `global`，如 `{{getglobalvar::名称}}` | 使用独立的全局变量命名空间 |
| `{{newline}}`、`{{newline::2}}` | 换行一次或指定次数 |
| `{{space}}`、`{{space::3}}` | 空格一次或指定次数 |
| `{{trim}}` | 移除宏前后的连续换行 |
| `{{noop}}`、`{{// 注释}}` | 无输出 |
| `{{random::甲::乙}}` 或 `{{random::甲,乙}}` | 随机选择一项 |
| `{{reverse::文字}}` | 反转文字 |

变量按出现顺序求值，支持嵌套参数。例如 `{{setvar::数量::2}}{{addvar::数量::3}}{{getvar::数量}}` 输出 `5`。不会先收集全文的赋值再回填前面的读取。

兼容范围：本项目没有酒馆的全局用户设置与聊天元数据变量存储，因此 local/global 两个命名空间目前均只在一次提示词构建中有效，不跨回合持久化，也不跨账号共享。脚本、插件宏、条件块、时间格式宏及其他未实现宏保持原文，不会执行；这不是完整的 SillyTavern 运行时。

`{{p0}}`、`{{p1}}` 等仍是程序提供的动态占位符，管理页会列出含义，不能删去或改名。先展开模板中的酒馆宏，再插入程序动态值，避免把剧情、人设或用户输入当作宏程序再次执行。原有存档与记忆流程不变，宏展开不产生模型调用。
