# 终端昵称头像

入口：个人终端 → 好友 → 昵称头像设置。按显示昵称精确匹配，去掉首尾空白；同名使用相同图片。URL 可选，留空保存移除绑定并恢复原头像。适用于已有角色、自由联系人和带 displayName 的群聊路人。

只保存于当前浏览器当前账号的独立 localStorage 键 terminal-nickname-images，不写入人设、联系人资料、存档、记忆、提示词或模型请求，不触发 API。刷新仍保留，换设备需重新设置。原有主要角色图片管理仍可用，昵称绑定图片优先显示。

验证：昵称绑定、未知发言者渲染、可选 URL 清除、不改写存档、非法 URL 拒绝，以及原角色图片兼容共 6 项测试通过；类型检查通过。

新增流程：点击“新增头像角色”，填写终端昵称，再进入该角色的可选图片 URL 设置。已有绑定按头像＋名字列出，点击编辑。

“重置所有自定义头像”只清空昵称图片存储；“主要角色头像管理”里的“重置主要角色头像”将主要角色本地图片覆盖和构图恢复默认，不清理昵称图片。若主要角色同名还存在昵称绑定，昵称绑定依旧优先，可在自定义头像处移除。相关回归 11 项通过，类型检查通过。
