# 学院私有编辑端

启动 `node server.mjs`（或现有后端启动文件）后同时提供：

- 游戏端：`http://127.0.0.1:8807/terminal`
- 本机编辑端：`http://127.0.0.1:8808/`

编辑端沿用米白背景、蓝色文字、衬线字体和无边框文字按钮。角色介绍中的“编辑角色”打开这个页面。保存后重新进入角色介绍会刷新卡片数据并回到角色介绍页。

## 角色卡片

左侧是角色卡片列表，可新增角色、上下排序。稳定角色 ID 自动生成，既有角色 ID 不可移除或替换，以保护旧存档。名字和序号是必填项。右侧为蓝色标签与黑色内容的成对条目，预置英文大写名、性别、能力、称号、身份、精神体、精神力等级、介绍和引语模板；除名字和序号外的展示条目均可删除，并可新增自定义条目、修改标签和内容、调整顺序。删除的条目不会在刷新时自动恢复。图片 URL 与隐藏提示词另行编辑。

隐藏提示词另设多行编辑区；初始内容从既有角色资料复制，之后独立编辑。它参与服务器的剧情提示词组装，不写入公开卡片。公开介绍字段仍提供角色身份和介绍上下文，隐藏行为设定优先，但不能覆盖固定身份字段或系统状态协议。

新角色用于新建存档；既有存档按原有角色集合生成，避免新增角色导致历史 MVU 操作或稿件不兼容。排序和公开介绍更新对重新进入的角色介绍页面生效。

## 世界书

按本机 SillyTavern 的 `public/index.html` 中 `entry_edit_template` 和 `public/scripts/world-info.js` 中 `newWorldInfoEntryDefinition` 重做编辑格式。支持多本世界书，条目按酒馆的紧凑标题行折叠展开，同一时间只展开一个。完整字段包含触发策略、位置、深度、顺序、概率、关键词、次要逻辑、扫描设置、包含组、递归、黏性、冷却、延迟、角色与标签筛选、生成触发器和额外匹配来源。

- 常驻条目直接启用；关闭条目不注入。
- 关键词按忽略大小写的文本包含匹配，扫描最近 depth 轮及当前输入；depth=0 仅扫描当前输入。
- 次要逻辑支持至少命中一个、不全部命中、全部不命中、全部命中。
- 插入位置支持系统规则之前、本轮行动之前、按消息深度插入；消息角色支持 System/User/Assistant。
- 同位置按 order 从大到小排列。

支持酒馆世界书 `{entries:{uid:entry}}` JSON 导入／导出，导入建立一本新的世界书；保留原 UID、完整条目字段、未知扩展字段及文件级元数据。条目可以修改、复制、删除和再次保存。界面只显示统一风格的“导入文件”按钮，实际 file input 始终隐藏。创建、改名、删除使用同风格的对话框。

这里对齐的是编辑格式及数据往返，不是完整 SillyTavern 运行环境。主线目前仍采用本项目的常驻／关键词、次要逻辑和顺序注入；向量、概率、黏性、冷却、递归等高级运行效果虽完整保留、可编辑与导出，尚未实现酒馆执行语义。人设辅助、事件候选等既有辅助入口仍使用服务器世界定义作为资料上下文。

## 保存与访问

数据存放在被忽略的 `server/private/editor-data.json`；已有文件保存前保留一份 `editor-data.previous.json`。临时文件写完后原子替换，旧版本保存会返回冲突提示，避免覆盖另一个窗口的修改。

编辑端仅监听 127.0.0.1，并校验 Host、Origin、跨站请求标记及写入令牌；不提供跨域读取。它是本机管理页面，不是带账号权限的公网管理系统。游戏端的公开 API 和角色卡只返回明确列出的公开字段，不返回隐藏提示词或世界书内容。完整编辑数据只能从本机 8808 编辑端读取。

`EDITOR_PORT` 可调整编辑端口；默认游戏端“编辑角色”链接使用8808。服务器编辑内容会随下一次请求读取，不需手动重启后端。
