# Mahjong tile artwork

Author: FluffyStuff. Source: https://github.com/FluffyStuff/riichi-mahjong-tiles
Pinned source commit: 26e127ba2117f45cdce5ea0225748cc0cfad3169

The 39 SVG files are unmodified copies of Regular/*.svg. Each file was verified against its Git blob SHA-1 at the pinned commit. Original suit glyphs are transparent artwork; the application displays them on Front.svg, and the locally bundled blue patterned playing-cards/Back.webp for concealed tiles. Haku.svg is intentionally blank. Images are bundled by Vite and served from this application, with no external image requests. The original PNG preview is not shipped.

The former solid-red Back.svg has been removed. The new back comes from AustinGabriel's CC0 deck; see ../playing-cards/NOTICE.md and its provenance manifest. Mahjong face glyphs remain at 80% size on the full ivory body.
