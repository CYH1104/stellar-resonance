# 完整备份与兼容性约定

2026-11-10：预设辅助区块解析配置 `preferences.presetOutputParsing` 接入完整设置备份；预设文件使用 `extensions.academy_output_parser`。本地下载/导入、云端载荷覆盖及覆盖前恢复均验证往返；旧文件缺少字段使用默认配置，未知配置版本/字段拒绝写入。详见 [基础自动解析](BASIC_OUTPUT_PARSING.md)。

## 格式

- 内部 Snapshot 仍为 version 1，可选 archive 描述独立持久化资料。
- 旧本地文件 version 1 与旧云端 stellar-cloud-save-v1 继续可读。
- 完整本地文件 version 2，必须包含 archive；云端 stellar-cloud-save-v2 必须包含 snapshot.archive。旧页面会拒绝新格式，避免静默忽略人设档案；请更新页面后导入。
- archive.version 目前为 1。未知版本、未知扩展字段、损坏的字段在修改任何资料前被拒绝。导出遇到尚未注册的 Snapshot 字段也会停止，不默认丢弃。

## 数据范围

统一采集入口为 useWorkspace.completeBackupSnapshot；本地下载与 createCloudWorkspaceBackup 均复用该入口。先 flush 人设/裁切编辑，再读取稳定的人设库和设置，并验证期间没有发生修改。

archive 包含独立人设、完整人设文字、备注、备忘录、编辑草稿、主人设及主页图片选择、隐藏的人设来源标记、昵称头像、独立角色图片设置及新建游戏表单。库中 sourceSessionIds 随新增导入存档 ID 一起重绑；发生人设 ID 冲突时保留已有档案，为导入档案分配新 ID。

本地下载包含人设库的图片 Blob（编码后保存）。云端只排除图片字节，保留人设文字及 HTTP/HTTPS 图片链接；同机拉取时按原档案 ID 保留云端有意省略的本机图片。API 和仓库令牌不进入备份。运行日志、诊断记录、模型原始输出不在采集范围内。

全部 sessions 原样参与备份校验，包含剧情、变量、记忆及 terminal 中联系人、好友申请、私聊、群聊、群管理、游戏抽签/命令/回应/互动/邀请、课表和终端记忆，不截取最后几条消息。云端的图片排除不删除终端文字记录。

## 恢复与失败

恢复前将当前工作区及完整 archive 写入 cloud-recovery:workspace。独立人设库在单个 IndexedDB 事务内替换，校验库修订号和数据基线；localStorage 和工作区写入失败时回退已变更的人设与设置，保留回退文件。多个独立数据库没有浏览器级的跨库事务，因此不得在全部步骤成功前显示“恢复成功”；若无法自动回退，明确提示保留页面并使用恢复副本。恢复租约在工作区数据库中跨页面互斥、持续续期；最终工作区提交检查租约归属。恢复前写入中断标记，成功提交时原子清除，刷新后检测到未完成恢复会提示并停止继续生成，直到恢复完整副本或完成新的恢复。

旧文件没有 archive 时，保留当前人设库、主人设和草稿；archive 内不存在的分区同样不代表清空。新文件显式给出空集合或 null 才表示相应分区为空。云端恢复保留设备 API 配置和密钥。
