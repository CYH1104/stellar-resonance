# 账号、邀请码与数据管理

新版本在生产账号服务中默认启用邀请码注册。原账号直接登录，不需要邀请码。注册成功即登录，无需发邮件或接入 QQ 互联。仅要求 QQ 邮箱格式，不声称邮箱已验证；QQ 邮箱别名不一定是数字 QQ 号。

## 管理员

从游戏同源 `/editor/` 登录管理口令，点击“账号管理”，或直接打开 `/editor/accounts`。无需先注册游戏账号。可以精确查询邮箱、生成密码重置链接，以及生成、统计、撤销未用邀请码。

服务器命令行也可以生成邀请码：

```bash
cd /home/ubuntu/stellar-resonance
pnpm invites --count 20 --batch 2026-W43 --note 公测第一周
pnpm invites --stats
pnpm invites --list --batch 2026-W43
pnpm invites --revoke XK7M-2Q9P
```

明文邀请码只在生成时返回或打印一次，不存库；列表仅返回批次统计。码忽略大小写和横杠。占用与注册在同一个事务中完成，一个码只能注册一次；已用码不能撤销，删除账号也不恢复邀请码。

## 忘记密码

用户先从注册邮箱联系管理员。管理员人工核对所有权后，在账号管理页查询邮箱并生成一次性链接，再回复至已核验的邮箱。网站不自动发信。

链接24小时有效；再次生成即作废旧链接。令牌仅存哈希，不写应用日志。重置页移除地址栏中的令牌，用 POST 校验；密码须8～128位，两次一致。成功后该账号的所有登录会话失效，所有设备重新登录。管理员页面及用户页面不返回密码或哈希。

## 游戏用户

截图所示“全部功能”菜单增加 **10 账号与数据**，完整功能面板也提供同一入口。包含：

- **重置游戏数据**：保留账号和密码；清理当前账号在本机的存档、记忆、人设库、世界书、预设、API Key、界面设置与日志。服务端推进该账号的数据版本并撤销登录会话，其他设备下次登录进入空数据区。
- **删除账号**：另删除服务器上的该账号凭据及密码重置令牌，撤销全部设备会话；清理本机该账号缓存。其他用户、学院公共档案和管理员口令不受影响。

操作要求当前密码、输入“重置数据”或“删除账号”，再确认。建议先从“存档与导出”备份；不会自动下载含私有内容的备份。

清理只针对当前账号的浏览器命名空间，不使用 localStorage.clear。其他同账号标签页收到维护通知后离开游戏，避免继续写入旧数据。若浏览器数据库被占用，显示实际失败原因并提供“重试清理本机缓存”，不会重复执行账号删除。

服务器不能立即擦除离线设备缓存。导出到设备的文件、服务器历史备份也不会随操作删除；其他设备重新登录后使用新数据区。浏览器清理失败或不支持数据库枚举时，应关闭其他标签页并检查该站点存储。账号数据没有自动云同步。

## 部署与回退

账号数据库在原位置，增加 invites、resets 表及 users.data_version 列，既有账号和密码不变；先保留更新脚本生成的备份。生产开放注册前先生成邀请码即可。若必须回退到旧代码，需匹配数据库备份恢复，旧版本的 INSERT users VALUES 不能直接用于新增列后的库。

可继续优化：管理员操作审计和历史备份保留策略；若未来有域名，可启用 HTTPS。当前版本不自动发送邮件、不创建公用 API Key，也不自动删除历史备份。
