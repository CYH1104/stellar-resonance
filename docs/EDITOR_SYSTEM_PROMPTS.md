# 学院档案管理：地图与内部提示词

在受管理口令保护的 `/editor/` 页面中编辑，修改自动保存到服务器的 `server/private/editor-data.json`，后续请求直接读取，不需要重启。此文件和备份均不推送到 Git。

地图页区分主地图、默认次地图及各地点次地图。地点支持增加、删除、排序以及名称、区域、简介、详细介绍、坐标和地标大小修改。已有内置地点作为默认模板导入；保存为空列表时不会自动补回。地点及图片 URL 仅用于页面展示，不拼入模型提示词。地图页面会同步服务器变更。

内部 AI 提示词页涵盖剧情、MVU、最终输出协议、视角、身份、续写、状态整理、人设、记忆、论坛、随机事件、摘要、建议及世界书边界。顶部可查看不同调用路径的实际消息顺序。内部规则仍在原函数、原条件和原位置调用；不会依据编辑列表顺序重新排序。

程序占位符写作 `{{p0}}` 等，旁边显示对应运行时数据来源。可修改周围文本，保存时检查必需占位符，避免意外丢失变量。用户控制的人设、历史、记忆、输入及预设／世界书插入位置只作说明，标注“此处的提示词不在此处可编辑”。用户预设和世界书的最终位置由该用户的启用、位置、深度与顺序决定。恢复内置默认仅移除该条覆盖值。

好感度继续由模型依据剧情输出，沿用已有数值，不强制每轮递增。仅完成且验证通过的回复提交状态；关系图连线的粗细、透明度随绝对数值变化，负值使用虚线。论坛按从早到晚排列，“最早／最新”操作实际滚动容器。
