# 基础辅助区块自动解析

预设页新增“自动解析辅助区块”，按预设单独启用和配置标签。默认解析 `foundation`；其他辅助标签（例如 `ECOT`、`辅助:草稿`）可逐行添加，不依赖某一款预设。只过滤明确配置的成对区块；未配置标签保留。正文、状态协议和普通 HTML 标签不能登记为辅助标签，避免误删正常内容。

流式、非流式回复走同一个过滤器，支持跨分片、嵌套、带引号的属性、自闭合标签及续写。过滤发生在正文/状态解码之前，辅助区块中的状态格式示例不会更新真实状态；新回复的辅助内容也不进入正文、后续历史和原始输出记录。未闭合区块隐藏到结尾；未完成回复仍遵守现有失败/重试规则。旧存档不重写，显示及发送正文历史时按所选预设过滤。玩家输入和预设提示词原文保留。

范围是辅助区块提取与正文保留，不执行脚本、SillyTavern 扩展或 HTML 美化规则，也不自动推断所有未知标签的含义。旧记忆摘要/终端历史不会批量改写。本功能不等于完整预设运行环境。

## 数据兼容

- 持久化字段：`preferences.presetOutputParsing[presetId] = {version:1, enabled, tags}`，沿用工作区设置存储，无新数据库。
- 复制预设复制独立配置，删除预设删除对应配置。切换预设保留未确认字段；配置草稿保存失败保留修改并允许重试。
- 预设导出在 `extensions.academy_output_parser` 保存配置，重新导入保留开关与标签。
- 本地完整下载、云端完整采集、覆盖导入、拉取覆盖、覆盖前副本/恢复均包含配置。旧文件缺少字段时使用默认配置；不改变旧文件的人设附加资料保留规则。合并存档沿用现有规则，保留本机预设设置，不激活导入文件的全局预设。
- 配置版本过新、未知配置字段或错误标签在导入/调用前拒绝；不静默降级。云端继续排除密钥、本地图片、运行日志及模型原始输出，保留图片 URL 和终端记录。
