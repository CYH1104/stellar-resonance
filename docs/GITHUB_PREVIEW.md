# GitHub 朋友试玩说明

日期：2026-10-16。版本：v0.11.2。

本次分享当前本机功能实现，并提供虚构测试世界。README 顶部列出从下载、首次准备到填写 API 的步骤；首次准备脚本联网安装开发依赖并构建，后续使用启动预览.bat。GitHub 未开启公网托管，应用只在各自电脑的127.0.0.1运行。

不上传原始隐藏人设／世界观、server/private、运行日志、API Key、用户聊天存档、node_modules、dist 和旧 ZIP 包。源码中的示例世界可以分享，后台缺少私有资料时读取它；维护者已有的私有资料始终优先，JSON损坏等异常不会静默替换为示例。两种数据集的标识不同，原本机存档不会当成示例存档。

本次完整验证：77项前端／工作区／SSR测试、64项Node服务器／模型测试通过，共141项。类型检查、生产构建通过。服务器测试已改为合成示例卡，不依赖维护者的私有文件。另在不含私有资料、Key、存档与依赖目录的发布快照上，以本机构建结果验证示例回退、首页、新建游戏和静态路径隔离；没有调用外部模型。

尚未在朋友电脑验证系统环境、网络或其供应商接口，未使用用户真实Key进行付费生成；首次依赖安装步骤需要正常 npm 网络。外观仍为当前功能骨架。
