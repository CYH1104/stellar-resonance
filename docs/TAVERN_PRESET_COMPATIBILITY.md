# 酒馆预设导入与兼容

2026-10-18。

后续已加入聊天顶栏正则编辑、预设正则导入和隔离 HTML 展示，见 `REGEX_AND_SOURCE_LINKS.md`。下文为预设入口修复时的兼容基准。

## 入口

剧情顶栏“预设”或侧栏“08 预设管理”，页面顶部点击“导入酒馆预设”。API 设置中也增加“导入／管理酒馆预设”直达按钮。可将 JSON 文件拖入预设管理页面；导入后自动选中并立即保存到当前浏览器，写入失败显示错误。导入文件不调用模型。

## 本次核对与修复

静态对照用户本机 SillyTavern 的 openai.js 和 PromptManager.js，以及用户提供的《双人成行v12.0——长夏未央.json》。没有执行该文件里的扩展脚本，也没有将其全文加入仓库。

- 明确导入按钮，显示总条目、当前列表和开启提示词数量。
- 保留 prompts 与 prompt_order 中的条目标识、内容、System/User/Assistant 角色、启停、相对位置、深度注入、注入顺序和触发类型。未插入的条目留在提示词库。
- 修复导出时将聊天历史后面的深度注入条目移动到历史前的问题。已有聊天历史占位时，按原列表顺序导出。
- 移除副 API 模式下按“正则”“状态输出”等关键词整条过滤用户预设的逻辑。启用条目仍按普通预设规则处理；内置协议和功能提示词的接口路由保持原分工。
- 现有编辑、分组、拖动排序、启停、新建、副本、导出及按预设保存采样参数继续使用。

实际文件验证：261 个条目、258 个列表条目；74 个开启的非占位条目，宏设置、注释等不产生消息的条目展开后为空。主接口模式和副接口模式均产生 54 条有效预设消息、9938 字符，无未展开的字母命名宏。导出再导入保留全部条目的内容、排序和开关。浏览器实选文件后验证自动保存、选中与刷新恢复。

## 兼容范围

支持姓名、人设、文本变量 setvar/getvar/addvar、相关变量操作、嵌套宏、random、trim、注释、换行及聊天消息引用等当前宏引擎已有语法。宏变量当前按单次请求隔离，不能当作酒馆跨会话持久变量。角色卡和世界资料占位继续映射本平台的数据来源。

不能将“酒馆预设可导入”称为整个酒馆及其第三方插件已经完整移植：SPreset、tavern_helper、正则扩展、脚本执行、部分供应商专属设置与上下文模板尚未实现同等行为。导入报告列出未执行设置。模型地址和密钥不随预设导入。自定义输出包装服从平台最终状态协议，以保留状态栏和小剧场的解析能力。

验证：208 项服务端测试、252 项前端/领域测试、TypeScript、生产构建及 20 项隔离浏览器检查通过；实际文件往返和消息构建另做只读检查。未使用用户 API。
