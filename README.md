# 群星共振 · 前端功能骨架 v0.1

这是可运行、可继续开发的网页前端，使用 Vue 3、TypeScript 和 Vite。功能、数据和样式已经拆开；收到 PPT 后可以在现有代码上调整视觉。大幅改变页面组织仍会需要修改组件，但存档、检索和服务器接口可以继续使用。

目前默认是**演示模式**：不调用真实 AI、不花费 API 额度，角色、地点和回复均为虚构样例。没有复制 RitusZhou 的源码、素材或用户 pro 文件中的脚本。

## 先打开看看

Windows 用户双击项目里的 `启动预览.cmd`。它会用本机 Node.js 运行已经打包好的网页，不要求安装开发依赖。保持命令窗口开启，浏览器访问 **http://127.0.0.1:5173/**。关闭窗口即可停止。启动文件会先查找 PATH 中的 Node.js，再查找本机 Codex 的 Node.js；都没有时会提示安装 Node.js 24.12 或更新版本。

不要直接双击 `dist/index.html`，网页需要通过本地 HTTP 地址打开。

建议按这个顺序体验：新建游戏 → 发送行动 → 开启骰子后发送新行动 → 打开记忆、人物关系、编年史、地图 → 存档与导出 → 刷新后继续游戏。

## 这一版能做什么

- 新建／继续、填写和编辑玩家人设、自定义开局、普通文字叙事输入。
- 模拟流式回复、停止、重试、续写、编辑／删除问答、回退、重演和选稿。
- 自己及在场人物的公开状态，受限制的本地 MVU 更新、人物关系图谱、事件编年史。
- 静态地图点击看公开介绍；没有探索、路线、当前位置、事件或人物移动。
- 事件记忆、每五个有效事件生成章节摘要、手记管理、来源定位、关键词检索。
- 可开关向量检索，本地 Web Worker 算相似度；演示向量是字频样例，**不代表真实语义效果**。
- IndexedDB 自动存档、JSON 备份导入／导出、当前选稿故事导出 HTML，可用浏览器打印成 PDF。
- 主模型／副模型／向量模型配置、多套接口档案、基本生成参数。
- 基础文字预设的启停、顺序、编辑、JSON 导入／导出，以及文本快捷按钮和下一步建议。
- 默认关闭的 D100 骰子。一次新行动投一次；停止、重试、续写、重演和选稿保留原骰点。
- 电脑与手机宽度适配、错误反馈、半截回复保留。

**已预留但尚未接通**：真实模型调用、朋友访问控制、服务器私有设定读取。真实模式请求同站点 `/api/*`，需要按 [接口文档](docs/API.md) 实现后端。前端演示验证不等于安全登录。

**后续补齐**：正式角色与公开状态字段、关系类型和变化历史、正式游戏时间、正式地图资料、实际向量模型；酒馆脚本插件仍待评估。首版 MVU 是受限状态更新协议，并非完整酒馆 MVU 运行环境；基础预设 JSON 也不是完整酒馆预设格式。

不包含世界书前端管理、角色卡、正则、宏、语音、音乐、绘图图库、3D、建造、战斗、经济背包、聊天模式切换、言语／举动输入模式、阅读设置、作者管理后台。独立手机和 PC 安装包继续延后。

## 数据在哪里

聊天、状态、记忆、向量、骰点和非敏感配置存在**当前浏览器、当前网址**的 IndexedDB 中，不用 Cookie 存剧情。刷新通常能恢复；清理网站数据、无痕窗口结束、换浏览器、换设备或换域名不能自动恢复。请定期导出备份；本地试用切换到正式域名前，也先导出再导入。

API Key 只在本次页面内存中；刷新后重新填写。接口档案和备份不保存 Key。真实模式下，Key 和必要的剧情上下文会发给你自己的 API，由后端转发给批准的模型服务。外部向量模型会处理用于编码的记忆文本，向量结果再保存本地。

私有作者人设、世界观和世界书应放在服务器非公开目录或数据库，不放在 `src/`、`public/`、`dist/` 或网页响应里。模型可见的设定仍可能被模型在回复中透露，不能把“不提供原文接口”理解为绝对无法推测设定。

当前没有自动云同步，也未实现同一存档在多个标签页之间的并发编辑协调；请用一个标签页编辑同一份存档。

## 开发与接服务器

Node.js ≥24.12，pnpm 11。项目依赖版本已固定，锁文件已附。

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm check
pnpm test
pnpm build
```

开发服务仅监听 `127.0.0.1:5173`。正式部署时把 `dist/` 交给服务器的 HTTPS 静态服务，把 `/api/*` 转发给后端；`preview.mjs` 只是本机预览工具。
