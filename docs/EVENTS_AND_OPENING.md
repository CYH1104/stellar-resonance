# 随机事件与初始开场白

随机事件由浏览器脚本按照设置概率判定，未命中不发送事件生成指令。命中后自动投骰并生成本轮，不再等待接受候选。跟随主 API 时，事件与正文在同一次请求中输出；明确选择独立事件接口时，先生成事件，再自动接入正文。重试或重演沿用本轮已经保存的类别与骰点，不重新判定概率。

剧情上方的事件卡片展示当前所选回复返回的 `diceEvent.description`，模型未提供有效骰子元数据时使用本轮实际事件摘要。生成前不展示占位说明或候选确认按钮。旧存档中尚未确认的事件可以点击“继续生成”恢复；准备失败可重试或跳过，不删除行动。

在“学院档案编辑 → 初始开场白”修改正文，停止输入约 650 毫秒后自动保存，也可点击“立即保存”。换行与空行会保留。服务器每次新建存档读取当前保存的开场白，无需重启；已有存档的开场不会被替换。旧编辑数据会自动沿用原有开场，旧客户端没有提交开场字段时也不会清空它。

模型接口显式返回的推理字段、思考标签和隐藏注释会被过滤，不进入剧情展示；不会额外调用模型来索取思考。测试可验证返回内容被隐藏，无法证明服务商未返回的内部推理存在。角色内心想法、精神体 OS 属于剧情状态，继续正常展示。
