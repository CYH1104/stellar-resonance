# 2026-11-27 剧情游戏邀约与观战交接

## 已完成

- 复用已确认正文后的终端通讯请求，支持角色发起六类游戏邀约；原文证据、角色ID与座位数校验，按来源去重，回退分支隐藏。
- 玩家参加/观战/婉拒入口；参加时替补让座，观战不占席位。斗地主与日麻本地自动策略支持全NPC对局；其他游戏复用原阶段请求。
- 公开观战投影、暂停/继续、历史小局回看；狼人身份与夜间私密信息不向观战者公开。
- 记忆正确区分参与者与观战者；角色邀约和游戏历史纳入完整备份与恢复。
- 只为当前或选中的小局计算观战投影，普通玩家牌桌不计算观战历史，避免随每次出牌重放所有历史日麻局。
