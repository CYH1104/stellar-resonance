# 预设冲突与补修隔离

## 导入

按 prompt_order 顺序检测用途、输出指令、模板与分隔段。只有明确重复的状态栏、美化、行动选项、小剧场／社交动态和摘要要求会关闭；未知格式、纯 content 包装、写作类规则只提醒。必开／勿动、字数、防截断及服务器 marker 保留。同名分隔条或 END／结束闭段，部件区逐条分析。

只调整开关，不删除原文。每项保存分类、原因、原始开关及恢复标记。预设页展示记录，可恢复全部或仅选项；恢复不会启用原本关闭的条目。备份和导出保留兼容记录，重新导入已处理条目不反复覆盖用户决定。提供“后续导入保留预设自带输出”开关，默认关闭；它不恢复外部 HTML 执行。

这是确定性脚本检测，不保证识别任意自然语言规则。仅靠正文关键词或未知标签无法判定冲突时保留条目并提醒，不会批量关闭所有 few-shot、思考或创作规则。

## 状态补修

前端不再附带写作预设；服务器也独立排除预设、示例消息、旧开场及聊天格式。补修消息从固定修复规则、当前状态、必要世界设定、本轮行动和固定正文重新构造。普通续写继续保留写作预设。手动补修仍一次请求，正常生成不新增模型调用；旧客户端选择的历史自动续写策略不在此变更中修改。

补修仍按实际开启模块输出。JSON/MVU 沿用校验，不从任意第三方展示标签猜测真实变量。MVU 事务失败继续拒绝整份补丁。

## 部分更新与正文

新增 partial 标记：普通字段错误仅跳过该字段，有效人物字段、在场状态及独立小剧场继续保留。前端显示“有效字段已保存，部分字段沿用旧值”，并保留补全入口。合法字段规范化不再被误报为整轮未更新。新标记支持备份回读。

标准平台状态块的截断内容不公开为 delta；逐切分位置回归覆盖 status、SR_STATE、UpdateVariable。内置显示另外过滤旧存档正文中夹带的这些完整／截断协议块。未知第三方展示文本仍保留为不可执行内容，隐藏思考和注释继续过滤。

验证使用确定性回归，未新增真实模型调用，不声称模型一定遵守格式。服务器正式世界卡缺失属于独立部署问题，本次不替换私有资料。
