# 固定预设尾部

预设页底部新增一个独立、固定的“预设尾部”条目。初始关闭、内容为空，用户自行填写，发送身份可选 system、user、assistant。沿用“保存预设”的提交流程；全部开启、拖动、删除普通条目及分组管理不应开启或移动它。关闭或内容仅含空白时不产生模型消息。

沿用 Preset 的 id、identifier、role、content、enabled、position 等既有字段，保留标识 `academy_preset_tail`。未使用的旧预设只显示空白关闭的编辑入口，不因打开页面而写入条目；实际编辑后才加入当前预设，其他预设不受影响。没有新增 localStorage、数据库或备份文件版本。

服务器按原有宏和内容校验处理该条目，再将其移至实际剧情请求末尾；世界书深度 0 插入、状态协议、叙事提示及续写控制均不能挤到它后面。内部定位使用 Symbol，不向服务商发送额外消息字段。不引入工具调用，不修改正文或终端的 API 绑定。终端独立调用及状态单独补全不应用这个条目。

本地下载、云端上传、预设导入导出、拉取覆盖和覆盖前恢复副本沿用完整备份入口，条目的正文、身份和开关随预设保存。运行日志、原始模型输出及密钥的排除规则不变。旧文件没有此条目时，继续使用原来的请求，不强制补入提示词。

验证包括：三种身份的实际 HTTP 请求末条消息、与深度世界书/状态协议共存、续写后的末尾位置、关闭/空白不改变请求、拒绝重复固定条目；本地/云端及酒馆预设格式往返；实际 IndexedDB 的拉取覆盖、覆盖前副本及撤销。浏览器操作验证独立开关、用户内容与身份保存、全部开启不影响默认关闭的尾部。已有慢请求、取消、迟到结果、保存失败、后台记忆期间的设置/存档与备份回归仍须通过；测试使用隔离数据和模拟模型，不使用客户 Key 或客户付费额度。

发布按 2026-11-13 的双端要求执行：8807、9000 同步完整更新；8088 不改。服务商是否支持最后一条为 assistant 等模型限制沿用其接口能力，本功能不代表所有上游模型均支持任意角色组合。
