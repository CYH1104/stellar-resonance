# 酒馆预设与状态输出兼容

本次以 main 为基础修复，未修改存档数据库名称或清理现有数据。

已使用用户提供的梦鲸思客 V4、双人成行 v12.0、小冰块 Gemini Claude V3.81 文件验证导入、排序、文本宏展开及完整提示词组装。测试只读取本机文件，不把预设原文提交仓库，不调用收费模型。

## 支持范围

- 姓名与人设占位符，以及 setvar/getvar/addvar、对应 global 文本变量、lastUserMessage/lastCharMessage、random、newline、space、trim、注释宏。变量仅在本次请求中存在，不会改写浏览器或服务器环境。
- 超大注入顺序按相对大小压缩，保留条目之间的先后关系。预设开关、分组、角色与注入位置仍按已有导入规则处理。
- dream_plot、dream_body、dream_after_format、maintext、story、正文等常见包装标签仅用于展示排版。未知标签按文字保留，不执行 HTML。
- 正文、群聊、论坛、日记及人物状态中的一至四层换行转义转换为真实换行；代码、URL、Windows 路径保持原样。

不执行预设里的 JavaScript、任意正则替换或扩展插件；这些行为可能修改状态协议或删除正文。它不是完整 SillyTavern 运行时。

## 状态兼容策略

游戏现有单次生成模式与独立状态副 API 模式均使用兼容解析，不新增自动修复调用。普通严格解析接口保持原规则。

- 角色 JSON 与 MVU 同时返回时，角色快照优先；兼容旧版整角色 MVU 写法，仅提取允许变化的字段，不覆盖 ID、姓名、性别、精神体种类，不重复应用增量。custom 变量仍经过原有路径与数据校验。
- 已知角色可按精确 ID 或唯一姓名匹配；兼容以 ID 为键的角色对象、数值字符串好感度和少量中文字段别名。不凭空添加角色或匹配模糊姓名。
- 人物字段逐项验证；缺失、无效或意外为空的字段沿用原值。完整有效的空在场名单表示全体离场，缺失或全为未知角色的名单保留当前在场状态。
- 论坛帖子、评论和小剧场分别校验，保留能识别的有效内容。兼容群聊的 name/text 别名、日记误放入 content 的对象和模型误填的配对分类；不为缺失的主角或精神体编造资料。
- MVU 块出现在正文之前或段落之间时，块结束后继续接收正文。模型返回的状态控制文本仍不会直接显示在剧情中。

状态 JSON 本身严重损坏、协议截断等情况仍可能需要续写或手动补全；已接收到的正文和日志保留。无法校验的字段或片段不会伪装成有效更新。缺失小剧场时保留之前已展示的小剧场。

兼容处理后的原始返回在“14 运行日志”中标记为“格式兼容记录”；当前浏览器最多保留最近 100 条，可手动清空。真正格式失败仍作为格式错误记录。成功处理不弹出整轮失败的红色报错。

固定输出协议在“学院档案编辑”的内部提示词页仍可查看和编辑。默认协议让角色状态集中在 SR_STATE 中，仅 custom 变量需要可选 JSONPatch，减少重复更新冲突；正文使用真实换行，JSON 内只做一层必要转义。

已成功导入的预设继续使用即可。此前因超大注入顺序而导入失败的文件，可在更新后重新导入；不需要清空浏览器存档。
