# NPC 好感度与变量校验

2026-10-18 本地修改。

NPC 好感度有效范围调整为 **-100～200**，允许有限小数。`src/domain/affinity.ts` 是范围、数值校验、JSON Schema 描述与关系线强度的共同来源；模型默认规则从同一范围生成，避免提示词和脚本互相矛盾。

负好感关系线采用淡红色 `#d99b9b`，保留虚线。正好感保留原强调色；线条宽度与透明度分别按负向 0～100、正向 0～200 缩放，正向超过 100 后仍继续变化，0 为中性。

借鉴参考卡的分层方式：

1. 正则和流式解析只定位控制块，JSON 解析处理补丁内容。
2. JSON Schema 描述约束；实际服务端、MVU 与提交入口使用同一数值校验，不仅依赖模型遵守提示词。
3. 对好感度补丁的明确十进制数字字符串作有限转换，例如 `"150"`、`"2"`；空字符串、布尔值、带单位文本和非有限数值不会转成好感度。
4. 先在副本应用补丁，校验失败不修改原状态；缺失字段继续沿用旧值，不把默认值应用到已有角色。
5. 面板与关系图读取已经提交的状态，不用展示正则直接改存档。没有新增 API 调用。

同时修复标签查找偏移未生效造成的解析死循环，以及跨流式片段结束标签丢失的问题。分片测试覆盖每一个拆分位置。

没有执行外部角色卡脚本，也没有引入完整 Zod 或 mvu_zod 运行时；当前实现是项目内的共享结构描述和实际校验函数。

旧存档原文继续保留，不批量截断或重写历史好感度。新生成与新提交受 -100～200 限制。作者自定义的内部提示词不会被代码强制覆盖；如曾自行写死旧范围，请到管理页更新相应规则或恢复该条目的默认值。

验证：208 项服务端测试、251 项前端/领域测试、TypeScript、生产构建和 18 项浏览器检查全部通过。变量事务、提交状态及调用路由的后续修复见 `docs/STATE_UPDATE_RELIABILITY.md`。
