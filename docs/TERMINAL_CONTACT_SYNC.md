# 终端消息和好友申请

已知角色主动私聊不再要求先成为好友，消息直接进入通讯列表，不自动接受或创建好友关系。角色可随正文主动发出好友申请，玩家自行决定是否接受。

添加好友支持终端码或存档角色姓名。重名时选择具体角色；通过姓名添加不需要暴露或虚构终端码。发送申请由副 API 判断接受或拒绝：优先使用已配置为终端接口的副 API，否则使用副 API 列表第一项。未配置副 API 时明确提示，不回退到主 API。

自动私聊、群聊和角色主动申请仍随正文的一次响应同步。已有群资料被模型重复输出且发生漂移时保留存档内资料，继续同步合法消息；未知角色或无效私聊单独诊断，避免丢失其余群聊。
