## 已修正

- 旧错误读取器仅检查 400/422，直接丢弃 500 响应体。本轮所有 HTTP 错误均在最多 16KiB、750ms 范围内检查；只返回固定分类，不回显、不记录原始错误正文。支持常见嵌套 error/message/details/cause/response/data、JSON 字符串和纯文本错误；深度与节点数有界。
- 5xx 使用 UPSTREAM_SERVER_ERROR，保留原始上游状态，不再提示“请检查模型名和参数”。角色、工具、预算、地区、无可用模型渠道等已知原因仍独立分类；未知原因不猜测。
- 400/422/5xx 失败附实际序列化后的消息数量、各角色数量、UTF-16 字符数、空消息数量、末条角色、对话后是否出现 system、流式标记、工具字段数量。均为计数/布尔/固定枚举，不带正文、Key、模型名、地址或私有世界书。角色顺序只是诊断，不自动压平或更改预设。
- JSON 错误及 SSE 中途错误都接通上述信息，并按原有轮次日志保存。没有自动重试、降级模型、改地址、改输出预算或删除提示词。
- 无新增业务持久化字段或数据库；使用既有运行日志，继续不进入下载、上传、导入、拉取覆盖和覆盖前恢复备份。既有业务备份结构未改变。
