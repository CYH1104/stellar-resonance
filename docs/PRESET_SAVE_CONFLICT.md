# 预设连续保存误报冲突

原因：草稿编辑加入默认字段的属性顺序与cleanPreset保存后的属性顺序不同；JSON.stringify将对象属性顺序视为差异，连续修改同一预设时误报外部修改。

修复：配置草稿脏标记及三方合并使用递归值比较，对象键顺序无关，数组顺序及正文空白保持有意义。未移除真正并发冲突检测，保存等待期间的后续输入仍保留为未保存。

范围：不自动忽略字段值规范化差异，不强制覆盖其他页面修改，不改变存档格式。

验证：32项定向保存/并发测试通过；完整前端851项通过；vue-tsc与生产构建通过。无新增持久化字段。agent-hub所需旧D盘路径不存在，交接记录保存在此。
