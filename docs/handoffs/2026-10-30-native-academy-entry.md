## 使用

先按 `native/UPSTREAM.md` 安装固定原版的依赖，再在项目根目录执行：

```text
npm run native:skin:install
npm run native:start -- --port <独立端口> --browserLaunchEnabled false --dataRoot <独立数据目录>
```

第一条构建学院扩展并复制到原版 global third-party 扩展目录；目录由原版加载器发现，不修改原版路由或源码。已有不同扩展占用同名目录会停止安装。根目录普通 `npm start` 仍是旧版，不能用它冒称已经切为原生。

首次启动沿用原版账号、引导、人设和 API 配置。自动恢复最近聊天由原生 `auto_load_chat` 设置决定，皮肤不私自改变它。该设置关闭时通过原版角色/存档入口打开服务器中已有聊天，资料仍在服务器。
