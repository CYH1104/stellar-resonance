# 记住登录

登录/注册页新增默认不勾选的“记住账号并保持登录30天”。成功后本机只记录邮箱，下次默认打开登录页并填写邮箱；密码不写入 localStorage、Cookie 或日志。服务器签发随机令牌，数据库仅保存令牌哈希，浏览器使用 HttpOnly、SameSite=Strict Cookie，HTTPS部署还使用 Secure。

- 勾选：Cookie及服务端登录令牌有效期均为30天，非滑动续期。
- 不勾选：浏览器会话Cookie，不设置Max-Age；服务端最长7天。浏览器的“恢复上次会话”可能恢复会话Cookie，不能承诺关闭窗口必定退出。
- 老客户端未传 remember：兼容原先7天持久登录。
- 勾选状态只在成功登录后记住邮箱；取消勾选移除所记邮箱。不存密码，也不在登录后失败时抹掉游戏存档。
- 主动退出仍撤销服务器令牌，密码重置仍撤销相关登录；保留记住的邮箱不等于仍然登录。
- 依赖浏览器允许保存Cookie。无痕窗口或清理网站数据后无法保证保留登录，不能绕过设备的存储策略。

账号数据仍按稳定账号ID隔离；保持登录不改变存档归属或添加云同步。本地8817仍保持免登录开发模式，正式账号服务更新后才显示此选项。

测试覆盖30天/7天到期、主动退出、非法remember类型，以及实际HTTP登录Cookie的持久/会话属性。登录页JS和服务端语法检查通过；完整服务端测试通过。
