# 列表模型与自动保存

基于 main 3f63c58。模型控件改为 select 列表，不再使用输入框的 datalist；继续自动获取、刷新、搜索、去重，已有选择在过滤列表外保留。

设置沿用工作区自动保存；API 完整后停顿约800毫秒自动注册/保存配置，不自动测活或调用生成模型，Key 仍遵循本机保存开关。新增副 API 完整后自动加入。人设档案、开场人设表单和当前会话人设编辑自动保存，连同备忘录、图片、头像及主页图片选项；新人设首次生成档案ID，后续编辑更新同一记录。头像裁剪调整后自动更新。预设条目、正则草稿和世界书条目/信息也接入自动保存。绑定会话、设为主人设、导入确认、删除及生成仍为主动操作。

共用 useAutoSave 处理停顿合并、串行写入、写入期间的新修改、离开组件时补写及错误重试。保存状态在表单内显示，未填写完整不显示已保存；API白名单或本机存储错误保留输入和错误说明。

验证：类型检查、前端回归、生产构建；本地浏览器用合成配置验证列表搜索、去重、自动API确认，以及连续修改人设不重复建档。未使用真实玩家Key、未调用付费模型。公网需更新构建后刷新。
