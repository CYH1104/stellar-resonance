The face SVG files are unmodified copies of Regular/*.svg. Each file was verified against its Git blob SHA-1 at the pinned commit. Original suit glyphs are transparent artwork; the application displays them on Front.svg, and a separate Mahjong tile back for concealed tiles. Haku.svg is intentionally blank. Images are bundled by Vite and served from this application, with no external image requests. The original PNG preview is not shipped.

`TileBack.png` is an unchanged copy of `Mahjong-2020/resource/tiles/64x64/face-down.png` from https://github.com/hkm-a/mahjong at commit `1069bf65e8b132602193c8e14a4d9f8616b74c9b`. It depicts an amber Mahjong back with an ivory tile body and bevel, not a playing-card back. The source repository's MIT license is retained in ../table-audio/LICENSE-mahjong.txt. SHA256: `d89ae24fe06521735c21c7992e5ef904f326e41715e3c2438167c18911129735`.

Mahjong face glyphs remain at 80% size on the full ivory body. The back image includes its own tile body and is displayed at full size.
