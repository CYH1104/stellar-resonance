# 向量配置只显示向量模型

基于main f8b6a17。向量API的ModelPicker显式传递embedding用途，经workspace、HttpGateway传入POST /api/models的kind字段；后端在返回模型名称前过滤。主/副文字接口不传该字段，保留原列表行为。向量用途切换会清空旧列表并取消旧请求，避免文字列表串入。

优先使用服务商明确的embedding任务/能力/端点标识，缺少元数据时按明确向量型号识别（如text-embedding、Qwen3-Embedding、bge-m3、e5等）。排除chat、reasoning、rerank等类型及无法确认的型号；空结果不回退全部列表。显示和搜索计数均基于过滤后的列表。服务商自定义别名可能被排除，可继续手填已确认支持embeddings的型号。

这是列表识别，不通过额外付费探测验证服务商声明；服务商错误标注或伪造名称不能仅靠列表保证真实性。保存的手填模型不被自动擦除，实际可用性仍通过原向量连接测试验证。不增加模型调用、不改变向量索引和记忆流程。旧前端没有kind字段时仍返回原列表，部署必须同时更新前后端。

测试覆盖混合列表、重排排除、未知排除、metadata别名、空列表、默认用途不变、非法kind调用前拒绝，以及前端用途传递与HTTP端到端过滤。类型检查、生产构建、完整前端367项及服务端311项回归通过；未使用玩家Key或调用真实模型。本机更新重启后刷新可测试，公网尚未部署。
