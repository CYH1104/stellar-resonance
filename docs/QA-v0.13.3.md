# v0.13.3 独立游戏设置

日期：2026-10-16（Asia/Shanghai）。上一版验证记录见 QA-v0.13.2.md。

顶部新增独立设置入口，取代原独立小剧场设置入口；使用game-settings面板，内部按人物设置／小剧场设置／快捷操作切换。玩家人设及快捷按钮从模型设置页迁移，沿用原savePersona和快捷操作保存。模型设置页只挂载ApiSettings。没有存档时提示先创建或打开存档再编辑人设；小剧场配置和快捷操作不要求存档。开场设置入口、右侧小剧场设置入口均指向新页，后者直接选中小剧场分类。小剧场中的配对偏好指引改为设置→人物设置，输出长度指引改为预设菜单。未增加NPC或服务器隐藏设定编辑器。

验证：92项现有Vitest通过、vue-tsc类型检查通过、Vite生产构建通过。本次为界面导航迁移，没有修改后端生成／模型测活逻辑、API分工或存储结构，没有为此增加镜像实现的测试。未进行实际浏览器点击或视觉验收，未读取用户Key或聊天数据。本轮仅本机更新，未上传GitHub。
