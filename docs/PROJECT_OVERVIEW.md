# 项目概览

《群星共振》已有星际 ABO 群像人设与背景，开发工作是把它们组织为可互动、可保存进度的游戏。正式人设、世界书与素材需要作者单独提供；本仓库以虚构测试内容代替私有设定。

## 已确定方向

玩家使用独立游戏界面，先 Windows EXE，后续 Android APK。客户端使用 Vue 3、TypeScript、Tauri 2。云端优先采用 Cloudflare Workers 与 D1，避免自行管理常驻服务器。玩家可自行配置 Key、模型、允许的预设和 User 人设。

原讨论曾考虑完全离线、内置完整酒馆和多账号切换，后期清单收敛为云端保密架构与酒馆格式兼容。这里按后期方案交接；不将完全离线保密、完整插件运行或多账号额度切换作为既定需求。

## 成功标准

MVP：朋友能打开 Windows 客户端，配置自己的 Key，与角色流式聊天，并恢复自己的进度。
Alpha：NPC、ABO 状态与关系、剧情事件和解锁可以随玩家选择独立演进。
Beta：通过 10～50 人模拟负载与内测，完善地图、背包和移动适配。

## 待作者确认

- 官方 API 与指定中转站的准确域名、路径及模型支持范围。
- 玩家身份方案、邀请方式，以及作者管理入口的认证方式。
- 正式 ABO 状态、关系、事件与解锁规则；具体素材及使用授权。
- 目标 SillyTavern 版本与优先兼容样例。
- 是否需要跨设备存档、玩家人设与卡片导入的范围。
- 开发者分工、GitHub 套餐、Cloudflare 账号与可接受预算。

这些问题不阻碍建立任务和交接文档，但对应功能实现前必须确定。
