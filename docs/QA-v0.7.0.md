# v0.7.0 API 分工与向量检索验证

日期：2026-10-15。

新增主／副／向量 API 角色迁移、任务路由、配置完整性和进入剧情校验。测试覆盖空副 API 跳过、部分填写拦截、向量按开关必填、Key 变更使确认失效、刷新需重填、继续存档在确认后恢复、切换剧情不改变摘要建议路由、移除当前剧情副 API 后改用主 API。用合成剧情执行五轮，检查建议与第五轮摘要实际收到指定副 API 档案和临时 Key。

向量测试覆盖独立端点、只发送待编码文本、返回索引重排、非法维度／重复索引／空列表／输入长度／响应大小，以及上游错误正文不泄露。客户端测试确认向量结果写入本地快照，备份不含临时 Key。所有外部模型请求均由测试替身接收，未配置真实服务商、未进行付费模型生成。

前端使用 Node 测试环境；工作区任务分配测试替代了浏览器 Worker，真实消息传递边界由已有检索测试覆盖。此前本地浏览器自动读取被策略拒绝，本轮未绕过，因此浏览器视觉及真实模型效果仍由用户试用验证。

旧版预设导入验证保留在 QA-v0.6.2.md。最终检查及服务版本见本次交付记录。

最终结果：51项前端／工作区测试、36项服务器／模型适配测试，共87项通过；Vue／TypeScript 和生产构建通过。预设采样参数跟随剧情接口的最后调整，又通过相关5项回归测试与类型／构建检查。停止脚本校验并停止旧实例后，已启动 v0.7.0；health 确认项目 aa996d19492b4f00、版本0.7.0，地址仍为 http://127.0.0.1:5173/。

连接修复补充：受限进程复现 MODEL_UNREACHABLE；正常网络权限重启后，通过同一本机 /api/models 路径得到预期的 UPSTREAM_AUTH（刻意无效测试凭据），传输验证通过。未调用真实模型。详情见 NETWORK_DIAGNOSTICS.md。
