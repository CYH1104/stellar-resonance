## 验证边界

这轮没有通过浏览器工具读取页面或截图；上一次本地页面读取被浏览器安全检查拒绝，没有用其他浏览器控制方式绕过。实际 UI 的最终显示和交互仍待用户试用确认。HTTP 接口测试不等于浏览器布局实测。

当前为本机原文资料联调，没有外部 AI、真实向量、完整世界书或正式 MVU 规则；没有进行真实模型质量或多人公网部署验收。

## 用户试用顺序

打开启动脚本弹出的页面 → 确认“本机资料联调 · 非 AI” → 新建存档 → 选择在场角色 → 发送文字 → 查看原文摘录、状态和论坛 → 点击地图看介绍 → 备份／刷新继续。原演示存档保留原角色，建议本次新建。
