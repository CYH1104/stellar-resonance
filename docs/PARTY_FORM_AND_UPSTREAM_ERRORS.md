# 聚会表单与上游错误显示

- 聚会创建页的好友勾选、头像和名字靠左排列。只在该列表覆盖全局 checkbox 自动外边距与对齐，不改变其他终端表单。
- 聚会氛围增加搞笑、休闲、欢乐、暧昧四个快捷按钮；type=button，不触发创建或API请求。写入原style字段，可继续手填，仍限制40字符，不新增持久化结构。
- 新错误诊断不再生成独立“端口”行。接口地址保留真实origin（用户配置的非默认端口仍属地址的一部分）。已保存失败卡只在展示时隐藏旧端口行，不改写日志或倒推旧状态码。
- HTTP拒绝保留实际upstreamStatus及提取的错误message；本机502包装不替代上游503/429等状态。HTTP200流内错误用providerStatus/providerCode表达明确返回的状态/代码，标签为模型返回状态，不能伪装成实际HTTP传输状态。没有明确数字不从报错文字猜测。
- 优先显示上游错误内容；未提供错误内容时仍保留原本的安全分类、状态修复原因和请求数量诊断。toast去重和完整模型请求上下文继续保留。
- 消息只提取错误容器及message，不转发完整请求、headers或其他响应字段。已知密钥、Authorization/Cookie、常见token字段、已知请求正文回显会遮蔽；文本有长度、读取超时和体积限制，HTML仅作纯文本处理。
- 新的上游字段只用于请求错误与运行日志，不加入游戏、人设或备份结构；原style与既有完整备份路径不变，运行日志按原约定不进入云端/下载备份。

验证包含预设实际setup函数、可编辑文本/忙碌禁用、不误提交、左对齐CSS覆盖、HTTP与SSE的502/503/429、无状态不猜测、已保存失败卡端口清理、密钥/请求回显遮蔽、旧状态修复提示、模型切换/取消和日志去重。测试使用模拟上游，不调用用户真实模型。
