# 十点半与大话骰新版规则

## 十点半

新局界面更名十点半，rulesVersion=ten-half-v1，目标10.5（21个半点单位）。A=1，2～10原值，J/Q/K=0.5，超过10.5爆牌，正好10.5自动停牌。五花/五张不过等层级、同总分比较最大单张及全爆无胜负全员1杯继续沿用。

内部kind=eleven、现有API任务名与存储主键保留，避免破坏原备份。所有操作、重放校验、亮牌和模型canChoose都按该局规则版本计算：旧的已开始牌局（包括旧v1/v2）仍按当局11.5规则结束，不重新解释既有发牌或追记酒杯；下一局才是10.5。界面为旧局给出历史规则说明。

## 大话骰起手散点

新局rulesVersion=liar-v2。每人仍5颗骰子，原始点数五个互不相同即散点；判断散点不把1的万能效果当对子。任何人叫号前，玩家散点可反复整杯重摇，仍散就继续，也可保留当前散点。出现对子自动封杯；非散点和开始叫号后不能重摇。

NPC在初始准备阶段由程序本地处理散点，不为摇骰额外调用模型。玩家散点时phase=rolling，暂停NPC叫号，直到重摇出对子或按“保留并开始叫号”。rolls保留初始骰、每人重摇次数、最后一手散点和封杯状态，随原游戏备份保存；不将其他人的初始或当前骰子发给模型。公开游戏摘要只称准备骰子，不广播玩家未选择公开的散点特征。

## 多家开与劈

轮到自己时，可以从其他已有叫号的参与者中勾选一名或多名。每人取本局最近一次bid（数量＋斋/非＋点数），各自对照全桌骰子总数独立结算；不能开自己、重复目标或没叫过号者。散点重摇须在任何人叫号前完成，之后不改变骰子，保证此前叫号仍可比较。

actual>=该家叫数（包含正好相等）：叫家胜、开者输；不足：开者胜、叫家输。普通每家输者1杯，劈每家输者2杯，所有家累加。赢这一家不因这一家喝酒，但若输另一家仍喝另一份。例开A/B，A够B不够=>开者1、B1、A0；劈则开者2、B2、A0。两家都够的劈=>开者累计4。

一次开/劈后本局结束，先逐家算完全部酒杯，再检查酒量和醉后结束。未醉且继续下一局时，由本次喝酒最多者先叫，杯数并列按原始座位顺序。现代challenge保存每家原叫号、实际数量、赢家/输家/杯数、每人总杯数与nextStarter；多家不伪造一个全局winner。旧v1局保持原上家单开，不迁移进行中的骰子。

## 策略、请求与保护

NPC仍每次一个行动请求并同时返回桌上多句对话，自动接到玩家或开骰结束。可以按服务器人设激进或稳重、合法地开局叫大数量或大点数、叫本杯没有的点数来诈唬；自身点数是否含该点不影响叫号是否合法。只能参考自己的骰子、公开叫号/聊天和概率，不能透视他人骰子。

模型只选择bid/open/split与合法targets，结算由程序执行。玩家开劈先落盘所有结果，再请求一次桌上接话；失败只补接话，不重摇、不重复扣杯。NPC行动及多句对话一并保存；非法目标/结果不写入。保留原有酒量上限、醉后结束和旧备份兼容；新字段未知版本在导入前拒绝。
