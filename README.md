# 群星共振 · 功能试玩 v0.20.7

记忆页只保留逐条补记，正常记忆的补记按钮置灰；显示聊天轮数和有效逐轮记忆数。缺失整条记忆也有对应占位供补记。手动检索和新增手记入口移除，自动剧情检索及已有手记保留。向量检索固定开启，须配置并保存向量 API；旧关闭设置及导入设置自动升级为开启。“补建记忆索引”只处理缺失／失效的索引，没有缺项时置灰。

API 设置页支持 JSON 导入／导出主 API、副 API、向量 API、功能路由及相关开关。默认不导出 Key，可勾选包含明文 Key 用于个人迁移。导入前确认替换，仅改变 API 设置；不含 Key 的接口仅保留当前同 ID、同地址的 Key。导入不自动调用模型，须保存 API 确认配置。游戏备份仍不包含 Key。

保留原来的开场、深色界面与三栏布局。先双击“首次准备并启动.bat”，准备完成后使用“启动预览.bat”。需要 Node.js 24.12 或更新版本；首次准备会联网安装依赖。打开网页后填写自己的主 API，副 API 可选，开启向量检索时才需配置向量接口。

## 本版状态解析与本机开发诊断

兼容模型状态 JSON 字符串中的未转义控制符、结构尾随逗号及外层 JSON 代码围栏。只做不猜测内容的语法规范化；缺引号、缺逗号、截断和不完整字段仍按原有限补修处理。

API 设置 → 本机诊断与报错 → 本机开发者模式（诊断）：首次设置本机密令，之后输入解锁。密令只以随机盐和 PBKDF2 哈希保存在当前浏览器，解锁状态和最近20条脱敏诊断仅在当前页面内存，刷新锁定，不进入游戏备份。只记录语法位置、规范化计数、补修次数及输出字符数／结束原因；不保存或开放思维链、原始输出、提示词、Key。此前失败的原始响应没有保留，不能据合成复现断定历史失败都属于同一原因。

## 本版小剧场

同人文至少800有效字符，模型须确认完篇，有开端、发展及合理结尾；精神体日记至少200有效字符，可从任意已知精神体（含未在场角色）视角写幽默见闻与搞笑日常。空白和标点不计入字数。过短或未确认完篇会在原有最多3次额外请求预算内补修，不额外打开新的无限重试；正文保留。亲密互动仅按明确成年、自愿及既有配对设定，性情节含蓄转场。

兼容截图中的 DRAFTINKG 标签变体与流式分片。场景卡和标签内正文保留。

## 本版精神体与正文

精神体姓名、外貌、性格、能力可在新建人设、人物设置和 user 人设库分别填写，并供 AI 填表和剧情请求使用。状态栏 OS 要求依据精神体自身性格写内心独白，不写动作旁白。玩家及 char 的异能独立作为 ability 状态展示；旧 identity 中明确标注的异能保留到独立字段。正文识别顶栏、DRAFTING、content 包装，保留内容与 Slate 场景排版；未知 HTML 继续作为文字转义。

## 本版状态栏

补全状态和小剧场按钮只在当前完整回合确实缺项时展示，修复后自动隐藏。精神力等级与第二性别合并显示，例如【A+级 Alpha】；user 与 char 的身份支持逐行显示院系／组织及年级／职位。身份仍作为 MVU 变量随剧情、切稿、回退和备份保存，服务器已知资料可补入同源旧存档。

## 本版世界书

顶部“预设”和“世界书”分别管理。世界书支持导入酒馆 JSON、折叠编辑条目、关键词与常驻触发、递归、概率、排序及指定深度插入；各存档独立选择使用的世界书，用户书保存在浏览器本地并随全部备份导出。只将本轮触发内容交给服务器，不增加模型调用。不支持的高级条目在兼容提示中列出并跳过。

原服务器角色和世界设定保留，可另外在 server/private/worldbooks/ 放置内置酒馆世界书；没有前端查看或导出接口。详细支持范围及部署方式见 [世界书](docs/WORLDBOOKS.md)。

## 本版记忆流程

每轮正文完成后，使用“API 设置 → 每轮记忆整理”选择的主或副 API，整理人物、时间、地点、user/char 行动、得失、约定和真实 MVU 数值变化。取消固定每五轮汇总；下一步建议仍与正文一起生成。

开启向量检索后自动为新记忆建索引；生成下一轮前结合玩家输入、在场／提及角色、地点和近期事件检索。未履行重要约定固定携带。向量检索在浏览器完成，失败回退关键词；索引失败保留文字，可单独重试。旧截取记忆不会参与新检索，可在记忆页点击“补记”从完整历史问答重建；打开存档不自动调用模型批量补记。

正常每轮一次剧情请求、一次记忆请求。开启向量时，有可检索记忆会多一次查询编码，新记忆再编码一次；随机事件候选、论坛评论回复、续写／状态补修及主动重试按实际触发另计。

## 其他功能

- 左侧人物状态和右侧最多四个小剧场可自行调节宽高；群聊以手机消息展示，精神体日记以篇名、作者、心情和分段第一人称正文展示，与即时精神体 OS 分开。
- user 人设库保存玩家自己创建的不同人设，支持 TXT/MD 导入、编辑、删除、头像裁剪及载入新游戏；同名不同内容分别保留，已有存档不跟随其他人设一起改写。
- 玩家、世界卡叙述者、场内 NPC 独立标识。主线“你”要求固定指玩家；姓名宏 {{user}}、{{char}}、{{persona}} 及部分旧版姓名占位符可用，{{char}} 不随 NPC 出入场变化。保持用户预设开关、顺序、角色和助手预填，强制隐藏已识别思维链。
- 角色第一性别与 ABO 第二性别分别传给模型；服务端固定资料可同步同一世界卡的旧存档，不覆盖玩家自定义性别。
- 论坛 AI 回复默认关闭，可指定主/副 API，支持文字与多种 JSON 返回格式；失败保留用户评论，可仅重试 AI 回复。
- 可选随机事件：每新回合 50% 概率准备候选，用户先拒绝或 Roll D100，再生成正文；重试、续写沿用候选与骰点。
- 已开启的小剧场、好感度与已知精神体 OS 缺项会有限补修；正文截断自动续写，二者合计最多三次额外请求。旧错位正文可在对应回合重演，生成约束不能保证任意模型语义始终正确。

- API 功能接口选择集中显示；支持原预设大分组折叠、导入／导出和旧分组恢复。
- 人设与状态栏支持精神力等级，随 MVU 状态保存与回退；具体升降规则由作者后续提供。

## 数据与隐私

分享代码不含作者私有人设或世界卡、真实 API Key、浏览器存档、日志、迁移记录、node_modules 或 dist。缺少 server/private/extracted-pro.json 时，自动使用 server/example/feature-demo.json 的虚构功能测试世界；这不包含作者完整剧情。

聊天、记忆、向量、人设档案和 API 设置保存在当前网址的浏览器本地存储。Key 不包含在游戏 JSON 备份中。独立人设档案库及图片尚不包含在游戏 JSON 备份中。真实模型调用、测活、向量检索、可选事件及论坛回复可能消耗所选服务额度。

仅监听本机回环地址。此版本用于本机功能试玩，公网部署前需独立实现账号、HTTPS 和服务端资源控制。
