# v0.13.0 独立预设与思维链隐藏

日期：2026-10-16（Asia/Shanghai）。上一版验证记录见 QA-v0.12.0.md。

参考 SillyTavern 官方 Prompt Manager 与 Reasoning 文档，未复制上游实现。预设从模型设置拆到顶部独立菜单；新建默认固定条目、另存副本、名称、导入导出、删除确认、提示词库插入／移出、搜索、全开关、拖动及上下移动、编辑草稿保存／取消、角色、深度／Order、多选触发接通。跨 chatHistory 的相对拖动会变更实际注入侧，同深度按 User／Assistant／System分组后按Order排序。当前入口只触发 normal／continue／regenerate，其余类型保留兼容字段。

新增 Preferences.presetParameters，每份预设只保存白名单采样参数，切换预设覆盖剧情请求而不改变API基础参数、地址、模型、Key或其他任务。旧条目没有独立参数时，以当前剧情接口参数初始化；只有重新导入或自行设置后才能恢复文件原参数，无法猜回旧版未记录的值。备份恢复、副本独立与固定条目不可删均验证。未插入的库条目不参与生成、导出时不进入prompt_order，原内容保留在prompts中。未兼容的工具模板、脚本、复杂宏、正则与供应商参数不执行，导入报告明确列出。

思考展示没有开关。供应商独立reasoning_content／reasoning等字段不读，thinking及thought标记内容块不转发。普通content内的Think、Thinking、Think_rules、Analysis、Reasoning、CoT等固定标签和HTML注释在状态协议解析之前移除。过滤器支持任意分片、嵌套和跨自动续写，未闭合时隐藏后续内容；思考中的伪造状态或结束标记不影响正文结束。模型结果中编码的标签在JSON解析后再清理一次；历史assistant和检索记忆不把已识别思考重新发回。新备份导出、旧备份读取、生成记录及事件／摘要记忆同步清理，污染向量失效；玩家预设文本、输入、人设与手工笔记不作为模型思考改写。故事人物想法和精神体OS普通文字保留。

测试先复现历史存档未清理的失败，修复后通过。新增覆盖任意分片和未闭合、嵌套、注释、独立推理字段与thinking内容块、思考中的协议标记、跨请求不泄漏、编码JSON值清理、旧历史不回传、备份不保存已识别思考及不删除玩家预设文字、相对拖动跨历史、深度分组、多触发、库条目往返、独立采样／副本／重开。

只读核对原文件：小冰块V3.81.json的374条和夏瑾 天琴座 Beta 3.82.json的144条，导入、备份恢复和导出再导入均保持条数；正常请求仅发送开启、已插入且符合时机的条目。未执行原预设、脚本或扩展，未上传原文件。

最终验证：86项前端／工作区／SSR测试、77项Node服务器／模型测试，共163项通过，类型检查和生产构建通过。本机按正常联网权限重启，health确认为v0.13.0，首页200，仍只监听 http://127.0.0.1:5173/。

没有调用真实付费模型，没有读取真实Key或绕过浏览器访问限制，因此未完成实际浏览器点击与视觉验收。固定解析器无法识别任意无标记、伪装为普通正文的推理；不承诺通用语义识别或完整酒馆运行时兼容。未闭合的思考标签可能同时遮住后续正文，隐私优先并由现有截断／补修流程给出反馈。本轮仅更新本机，GitHub试玩分支仍为之前上传的版本。
