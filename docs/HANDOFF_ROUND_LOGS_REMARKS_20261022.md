# 轮次运行日志与人设备注

基于 598732d。

运行日志按 sessionId + turnId 合并，显示会话名、轮次、记录数、异常数和最新时间。展开后按时间先后显示生成结果、兼容记录、后台报错和变量变化。重说/重试保留在原轮次并提示生成次数；跨日期仍归入原轮次。缺少来源 ID 的旧记录不强行合并；已移除楼层优先使用原日志保存的轮次，无信息时显示历史楼层。原始记录和最多 100 条的保留策略不变。

user 档案名字旁新增备注入口，编辑框自动增高、自动保存；备注直接显示在名字旁，支持清空。备注字段 remark 与 memo、人设字段分开保存，只属于本机档案元数据；生成、主人设、会话绑定均继续只传递 persona。旧数据无需迁移。

验证包括跨天归组、同轮重试、不同会话/楼层隔离、无来源记录、备注独立存储及清空；隔离浏览器验证分组显示、备注编辑、自动保存、刷新恢复与模型人设内容隔离。玩家实际浏览器数据未修改。
