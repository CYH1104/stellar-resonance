# 功能需求

## 第一阶段：网页 MVP

- 响应式聊天页面：电脑与手机可以登录、输入、发送、停止生成、看流式回复、处理错误与重试。
- 设置受支持供应商和模型，提供一个基础默认预设与玩家人设编辑。高级预设顺序与导入在 Alpha 实现。
- 玩家 Key 默认只在页面内存中使用；刷新、退出后重新输入。主题偏好可在浏览器持久保存，Key 不随设置保存。
- 服务端验证玩家身份及会话、存档、变量的所有权；玩家能恢复自己的聊天和进度。
- 作者通过受保护入口导入世界书，建立公开、已解锁和隐藏分级。服务端先过权限与剧情状态，再执行基础触发和预算规则。
- Prompt 在服务端拼装，完整作者世界书、私有规则和 Prompt 不返回浏览器。
- 基础变量包含类型、默认值、范围和版本，更新在服务端校验并持久化。
- 手机软键盘、中文流式分片、断网、取消和后台返回均有可用行为。
- 不可信模型输出安全呈现；身份、CSRF、跨域和上游请求边界按实际实现测试。
- 核心引擎、玩家隔离和目标浏览器验收通过后，将受控预览链接用于 2～5 人内测。

## 第二阶段：Alpha

完善角色立绘、资料与关系面板、正式 ABO 状态、NPC 记忆、事件解锁、高级预设、安全正则与更完整存档操作。

## 第三阶段：Beta

地图、背包、更多格式兼容、10～50 人模拟负载及安装包需求评估。第一阶段的手机网页适配不依赖 APK。

## 验收原则

每个支持项有虚构样例和可复现结果；成功和授权失败路径同时验证。网页形态不提供额外的秘密保证；浏览器收到的内容视为玩家可以读取。真实部署、供应商费用与作者资料使用遵循已确认的配置和任务范围。
