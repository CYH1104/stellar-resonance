- 初次错误只剩“尚无回复”占位；HTTP错误记录原先没有关联具体轮次、稿件和调用。
- 连接测试在后端将输出预算设为512并清除可选采样项；正文使用当前预设的有效参数。省略零值惩罚参数的兼容补丁在本地严格接口中有效，但用户实测该补丁后仍400，**不能将其写成已确认根因或该渠道已恢复**。

- 完整更新后用户仍表示只有原来的400。当前安全分类未识别到更具体原因，正在等待用户从服务商请求日志提供该次失败的详细错误句；不索要Key、完整请求或私有提示词。

## 已完成实现

- `completionProfile`只在发送时省略frequencyPenalty=0、presencePenalty=0，不改保存配置。非零值、top_p、temperature、模型、地址和输出预算保留。正文、记忆、人设、终端及辅助文字调用一致处理，不增加自动重试。
- 连接测试成功文案改为“基础请求成功”；保存确认原文已注明不代表模型生成测试。
- HTTP正文失败按真实protectedGeneration关联会话／轮次／稿件／callId，避免与后台任务混淆。日志记录请求的实际数字采样参数；不把后端另有覆盖的探针误标为正文预算。
