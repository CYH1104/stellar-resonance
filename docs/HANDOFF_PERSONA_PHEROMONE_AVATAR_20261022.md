# 信息素与 user 头像交接

基线：main 00dab386。用户要求核对截图第 7/8 项，缺失部分直接实施；已先在 Slack 报备。

## 核对结果

频道另一位 GPT 最近完成：预设分组和文件顺序、取消预设长文本限制、人设输入焦点与高度跳动、API 自动保存和模型选择、小剧场列表滚动。main 还包含自动部署及 systemd 校验修复。本轮保留以上改动。

第 7 项原来只有信息素表单，没有明确的 AI 生成协议；other 有备注时，按整个字段补空会挡住信息素。第 8 项原来只有方形裁剪及固定 34px 圆形显示，没有尺寸/形状选项。

## 已修改

- AI 人设请求的系统消息明确要求在 other 中输出独立的“信息素：具体气味或设定”一行，保留原有信息素；根据愿望、第二性别和世界观补全。Beta 或明确无信息素应遵守设定，可填“无”，适用规则不明则留空。使用现有数据结构，不新增不兼容的模型 JSON 字段。
- 合并 AI 草稿时单独补空信息素；已有其他备注保持，玩家已填信息素（包括“无”）不会被替换。仍只有用户主动点击才调用一次模型。
- 人设图片与头像区域新增尺寸小/中/大（高度 26/34/48px）与正方形/圆形/长方形。长方形宽度为高度的 1.4 倍，支持全部九种组合。提供即时对话头像预览，没有图片也能设置。
- avatarAppearance 跟随每份本机 PersonaFile 保存，账号隔离沿用现有 IndexedDB 规则；新增、复制、切换人设和自动保存均处理该设置。旧人设默认中号圆形，不升级数据库、不重写原图。头像显示设置不发送给模型。
- 对话页通过共用 UserAvatar 显示选择的外观，并监听档案保存通知刷新头像；仍可隐藏头像。现有按姓名、人设原文和身份匹配档案的规则保持，若同名档案资料相同仍沿用原规则选择。
- 图片裁剪仍保存 512×512 PNG 和完整原图，显示时按所选外观裁切，不修改原始图片。头像外观与图片一样属于本机人设档案，不属于剧情 JSON 备份中的 AI 人设字段。
