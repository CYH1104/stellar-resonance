# v0.17.0 手机群聊、精神体日记及叙事视角

日期：2026-10-16。上一版 QA-v0.16.0.md。

反馈循环 node --test tests/narration-diary.test.mjs：新增玩家身份锚点和第一人称日记要求两项测试，原实现两项失败；补齐后转绿。用户提供的正文示例确有“你”被切换为char的问题。原生成只有泛化user描述、未绑定第二人称与当前姓名；续写仅要求承接断点；精神体模板只有独立片段指令。该循环检验实际发送的生成协议，不是对真实模型语义输出的证明。

新增服务端narration模块：playerId固定player，playerName来自规范化玩家人设，正文第二人称归player，NPC第三人称。主系统规则和当前玩家行动前均加锚点；错误历史不能重新定义身份，继续动作事实但恢复正确叙述。自动/手动续写携带规范姓名；只补状态强调不互换user/char。预设开关、消息角色、顺序、助手预填均保留；没有改用户预设文件、全局替换代词、自动重写旧稿或增加视角审查模型请求。任意LLM仍可能违反语义约束，需实际测试；旧错位正文可重演。

群聊组件只读手机样式：外框、状态装饰、公开姓名头像、左右气泡、实际发言人数、按原消息顺序；无假发送功能。新内容在原来接近底部时滚动跟随；查看旧消息时保留阅读位置。精神体日记为纸页样式、篇名、可选故事日期、心情、规范主人与精神体署名、段落及结尾。未知日期不使用现实时间填充；旧片段不假装已经改写为日记。原ResizablePanel和浏览器布局偏好继续适用。

TheaterSetting新增可选templateId，兼容旧名称/旧内置指令识别精神体日记；仅旧内置文字迁移为新要求，自定义内容保持。TheaterScene新增可选diary(ownerId,title,content,date?,mood?,ownerName?,spiritAnimal?)。结构校验、实际已知精神体主人和第一人称检查用于实时生成；主人姓名/种类由服务器规范值覆盖，不采信模型伪造值。日记正文与即时spiritThought独立。确实没有已知精神体时允许说明缺少资料，不造新物种。缺失/无效日记进入既有状态补修，正文固定，最多共享三次追加请求。旧完整轮补全仅替换缺结构的旧日记，保留已有论坛、其他有效小剧场和旧事件记忆去重；备份/恢复支持新字段，旧格式继续可读。

验证：123项Vitest、105项Node，共228项自动测试通过；类型检查及生产构建通过。新增手机与纸页SSR、四窗实际路由、HTML转义、模板迁移、自定义要求保留、新旧备份、日记与OS独立、玩家身份上下文与错误历史/预设边界、续写/补修控制、规范精神体署名、缺日记自动补修及缺资料回退、旧日记补全保留正文论坛；既有功能回归通过。未读取真实Key、未调用真实模型、未进行浏览器点击或视觉验收（此前访问限制仍遵守）。本轮只更新本机，未追加上传GitHub。
