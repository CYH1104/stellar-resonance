# user 档案去重与手机导航

基于 main d05d691。档案列表原来只按 JSON 文本比较档案库和会话人设；编辑后会话中的旧内容重新出现，容易再次保存为另一份档案。

- 本机档案新增 sourceSessionIds 元数据，在开始编辑时记录对应会话；自动保存、重选和刷新后仍识别为同一档案。会话人设与剧情不会随档案编辑自动改写，仍使用原来的显式绑定操作。
- 旧档案与会话按规范化字段比较，避免字段排列和缺省字段产生假重复。保存过程中重新选择会话条目时，优先解析到已保存的档案 ID。主动载入为新人设仍保留独立副本，不按姓名删除既有数据。
- 人物状态、小剧场在顶栏直接显示。取消手机统一“菜单”折叠；创作配置、更多、存档各自作为顶栏下拉入口。窄屏自动换行，手机下拉框在实际顶栏下方展开，并可独立滚动。

验证：新增 IndexedDB 来源关联与规范化去重回归；实际 Vue 页面验证 320/375/679/1280 宽度、手机菜单边界，以及两次改名自动保存、重选、刷新后仅一份档案。类型检查及生产构建通过。测试使用隔离浏览器与合成档案，未修改玩家实际本机数据。

既有独立档案不自动删除；如以前主动或误保存了多个实际档案，需确认内容后手动删除不需要的副本。

## 主人设与会话绑定的后续修复

复现路径：选中已保存档案，绑定到另一个会话，然后不重选档案直接继续修改。原实现未保存新绑定目标的 sourceSessionIds，列表把旧会话人设重新作为条目显示，实际档案 ID 并未增加。

绑定时持久保存目标会话 ID；每次编辑保存前，还根据上一次保存的人设捕获新关联会话，覆盖设为主人设后新建会话再编辑的情况。设为主人设在完成自动保存后复用现有档案，不再无条件再次保存。显式新增/载入为新人设仍保留原行为。

隔离浏览器验证连续两次设为主人设、连续绑定、绑定后直接改名及刷新；修复前列表由 1 变 2，修复后始终只有同一档案且 ID 不变。补充来源关联回归，10 项相关测试、类型检查与构建通过。
