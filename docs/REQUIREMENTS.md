# 功能需求

## MVP

- Windows 客户端含聊天、角色显示、设置与玩家人设入口。
- 支持消息发送、流式回复、停止、错误提示与重试；聊天与存档按玩家保存。
- 通过认证网关访问服务端；供应商按服务器认可的 providerId 选择。
- 玩家 Key 经 TLS 转发，默认仅当前会话使用；可选持久保存需要安全凭据方案。
- 规范化角色卡与世界书。作者导入独立于玩家内容输入。
- 服务端按可见性、玩家剧情状态、关键词与预算选择世界书片段。
- 变量有 Schema、默认值、版本与持久化；服务端判定权限和更新。
- Prompt 仅在服务端拼装，前端不能读取作者全量资料或完整私有 Prompt。
- 上线内测前完成玩家隔离、秘密边界和 Windows 产物检查。

## Alpha

补充角色资料与关系面板、ABO 状态、NPC 独立记忆、事件解锁、常用预设与安全文本正则、存档管理。

## Beta

地图、背包、事件记录、更多兼容项、10～50 人模拟负载、Android APK 和移动体验。

## 验收原则

所有“支持”都有可复现样例与明确限制；成功路径和权限失败路径一起验证。前端不能宣称通过持有作者加密包实现不可提取。Key、模型供应商、原始私有内容和玩家数据不得进入调试输出或提交历史。
