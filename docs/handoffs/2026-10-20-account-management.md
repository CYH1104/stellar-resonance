# 邀请码与账号维护交接

已按 `0004-account-plan.md` 实现邀请码、管理员密码重置链接，并追加用户账号删除和数据重置。用户入口在截图所示全部功能列表“10 账号与数据”，功能总览面板也提供入口；没有把删除操作放到顶栏。

实现要点：

- 生产服务默认要求邀请码，已注册用户原密码仍可登录；旧五列表迁移增加 data_version。
- 邀请码占用和注册同一事务，一码一次；哈希保存。管理页和 `pnpm invites` 生成/统计/撤销。
- 复用 editor cookie 鉴权，新增 `/editor/accounts`。精确邮箱查询；重置链接有效24小时，重发使旧链接无效、用过即失效、重置清除所有登录会话。重置页不显示账号；令牌从地址栏移除，前端用 POST 校验。不发邮件、不使用 SMTP 或 QQ 互联。
- 删除/重置要求当前密码、确认文字和确认对话框。删除仅该账号凭据；重置保留账号，通过 dataVersion 隔离旧数据。两者撤销所有设备会话；当前浏览器只清理该账号的数据库与本地键，其他账号不动。
- 其他设备离线缓存和用户导出的文件不能即时远程擦除；服务器旧备份也不自动清理，已在界面和文档说明。

验证：服务端账号并发、迁移、过期/重放、全设备注销、账号隔离和 HTTP 权限测试通过；客户端命名空间测试通过；类型检查及构建通过。隔离浏览器走完邀请码注册→P1入口→重置→重新登录→删除→拒绝旧账号登录，以及管理员生成邀请码→查邮箱→发放链接→重置密码→旧密码拒绝、新密码接受、旧链接拒绝。均未触碰公网真实账号，未发送邮件或调用模型。

维护文档：`docs/ACCOUNT_MANAGEMENT.md`。发布后首次新注册需先生成邀请码；现有管理员编辑口令独立于游戏账号，不会因该功能失效。尚未部署公网。
