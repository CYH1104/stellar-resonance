# 8088 原生预设兼容修复（2026-11-01）

## 根因及修改

学院原先在原生 JSON 进入酒馆前，额外要求 `prompts`、`prompt_order`、唯一 identifier、固定角色枚举及旧采样范围。酒馆原生能够加载的旧文件因此提前被误报为不兼容。

原始预设现在只经过 JSON、凭据、原型字段和资源保护检查；默认值、旧字段迁移、提示项和采样含义交给未修改的 SillyTavern PresetManager、PromptManager 和 ChatCompletionService。原始扩展字段保留。学院自己的预设库版本和任务绑定仍单独校验，错误不再统称“版本过新”。

请求预算也使用原生 `presetToGeneratePayload` 得出的输出长度和温度，避免导入成功后仍被学院旧采样设置覆盖。接口地址、模型及密钥仍使用用户本次选择。

人设助手只检查人设任务选用的 API；其他任务未配置不会把它重定向到设置页。原生模式的密钥与预设保存提示改为与服务器实际存储一致。

## 验证

- 原生源码 1.19.0 未修改；独立浏览器实际调用原生预设保存、应用和参数转换，核对缺少字段、旧 `main_prompt`、重复 identifier、64000 输出、3.2 温度及扩展字段。
- 实际 SDK 与学院请求适配器的参数结果对比一致，没有调用模型。
- 完整前端测试 959 通过、2 跳过；后端测试 459 通过、4 跳过。后续初始化时序和代理修正后，类型检查及相关 119 项前端测试、4 项页面测试通过。
- 完整备份继续使用统一采集入口，原始预设经下载、云端净化和再次解析保留；凭据与本地图片继续排除。没有新增持久化格式。

## 发布范围及未完成事项

仅更新独立 8088 迁移版。保留用户选择的生成暂停，不安装服务器 Chrome；预设导入不等于已验收真实模型生成。8807、9000 不更新。

本次没有完成世界书双路径合并、世界书全部原生语义兼容、服务器回复层思维过滤和完整迁移验收。预设兼容修复不能作为这些项目已经完成的证明。
