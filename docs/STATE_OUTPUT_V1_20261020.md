# 频道反馈修复交接（2026-10-20）

依据频道 #所有-我是奶人 当日 00:45 与 10:38 两条消息及附件，实施有限格式归一化和 state-output-v1。基于回滚到 141455c 后的主分支继续修复。

## 输出与结算

- 网站正文、状态、论坛和小剧场使用一次模型请求；不因格式缺失自动发起额外补全请求。旧输出仍可导入，但新提示词只要求一套协议。
- 正文后依次输出 `<SR_STATE>`、论坛、按槽位排序的小剧场、`<SR_DONE>`。状态附 schemaVersion 和每次新生成的 requestId；错请求、重复角色、混用 MVU 数值更新不重复结算。
- 每个相关 NPC 显式提交 `affinity: {delta, reason}`，包括 0。理由是简短剧情依据，只存审计信息，不进入角色卡正文，不要求模型私密推理。
- 好感总范围按最新频道改为 -100 至 100，支持小数。通常正向 +0.5/+1，超过 +3 提醒但不强制截断；负向没有每轮固定幅度上限。记录请求增量、实际增量、前后值和是否触及总边界。
- 新角色先按唯一 ID 注册，初值 0，再应用明确增量。建立的精神体首次登场即要求 OS，每轮重新返回；不编造精神体身份，不把旧 OS 当本轮已返回。
- 文本字段使用明确的 set/keep，保留身份事实边界。缺项不会删除其他有效字段；遗漏在场角色的整行不会被解释成离场。
- 自定义变量只允许已登记路径和类型；非法事务整组拒绝，不部分应用。补全只能写入此次授权的路径。

## 补全与存档

- 手动补全按缺失角色、字段、槽位和自定义路径执行；已接受的好感、关系和其他模块保留。补名单也不能重新覆盖已有好感。数值相对本轮开始状态结算，保存绝对结果，避免重复加算。
- 请求绑定当前会话与分支；运行期间切换或修改分支的迟到结果不能覆盖当前稿件。IndexedDB 写入检查持久化版本，旧页面不能无提示覆盖新页面的数据。
- 旧存档超过 100 的数值按新范围迁移，并保留迁移前初始状态、各稿件原始结果和记忆记录，随备份导出。涉及旧值的记忆待重新整理，旧向量失效；不重新随机生成数值。
- 记忆按实际已应用的前后状态生成，不把被拒绝的模型命令写成既成事实。
