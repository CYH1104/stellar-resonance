# 两端 API 保存、运行日志、HTTP 提示与流式渲染修复

共同应用于 8807 与 9000。用户已要求 Codex 接手，WB 的写入任务已取消。

- API 保存只确认本次修改的接口；明确保存未确认的接口也能完成确认。无关的失效副接口不阻断保存。确认有 15 秒超时，配置按 ID 合并，删除不会复活，写入失败和保存期间的新草稿会保留。预设及世界书编辑器先提交输入再采集快照。
- 顶栏增加独立运行日志入口。无存档、正在输出、有未保存设置时均可查看，返回 API 设置仍保留草稿。
- 已知的 HTTP 400–599 错误通过顶部提示显示，五秒后消失，同次错误不重复弹出。HTTP 200 的 SSE 错误仅在明确带有上游失败状态时显示该状态。HTML 错误页与启动连接错误也覆盖。运行日志保留脱敏后的任务、模型、地址、耗时，重新打开页面区块不会复活旧提示。
- HTML 分块保留独立 style 的作用范围，完整文档与独立围栏保留自身样式。实际 SpiritDiaryView → TheaterContent → StoryContent → sandbox iframe 链路已验证普通内联 div 样式；截图对应完整原始日记未取得，采用同类内容验收。
- 流式输出复用历史状态、补修标记与 iframe 上下文，文字增量不再重复回放每个旧楼层；分支、变量、人设与状态变化仍会刷新。滚动测量合并到下一帧。

未新增持久化字段或存档版本。全部人设、剧情与终端记录沿用现有完整备份入口；运行日志、原始输出和密钥仍属排除项。

验证：731 项前端测试通过，完整后端测试通过，类型检查与正式构建通过。隔离浏览器实际点击 API 保存并重载，检查 400/502 单次提示及五秒消失、失败草稿保留、日志切换与手机视口。两种终端能力配置均使用该验收。

性能对照使用同一个真实 StoryView、100 轮合成历史、每轮 5600 字、12 批文字增量：修复前中位数约 93.9ms，修复后约 32.5ms（均含两次动画帧等待）。正文逐字一致，停止与手动上翻检查通过。此数字衡量本机渲染，不代表模型生成或网络速度。
