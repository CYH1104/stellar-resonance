# 用户中转接口记录

管理员登录 `/editor/` 后进入“账号管理” `/editor/accounts`，点击“查看接口记录”。上方邮箱留空显示全部，填写邮箱则精确筛选。

在服务器项目目录执行：

```sh
node scripts/relays.mjs
node scripts/relays.mjs 用户@qq.com
```

自定义账号目录时，将目录作为第二个参数；查询全部账号时第一个参数使用空字符串。

记录包含账号邮箱、接口 origin（协议、域名、显式端口）、有效端口、首次及最近观测时间、观测次数和操作类型。操作类型区分配置接口、模型请求、连接测试和查询模型；观测不代表请求成功或模型生成完成。默认 HTTPS 端口为 443，HTTP 为 80。

地址由服务器处理实际请求时提取；不接受客户端提交账号身份或记录内容。不会记录密钥、URL 用户信息、路径、查询参数、片段、请求正文及模型输出。前台接口设置页说明此记录用途。记录仅管理员和服务器维护人员可查询，普通账号不能查看其他账号。

更新前的历史不会补录；更新后首次配置或请求时开始记录。每个账号保留最近使用的 100 个不同地址，查询最多返回最近 200 条。数据在账号库 `relay_origins` 表中，重启保留；删除账号时删除对应记录。该功能用于排查异常地址，不能仅凭记录认定内部配置被盗用，也不会自动封禁地址。
