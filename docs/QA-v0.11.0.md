# v0.11.0 正文截断与自动续写

日期：2026-10-15。上一版记录见 QA-v0.10.0.md。

先以回归测试复现旧问题：合法状态块后即使没有独立结束标记，旧解析器也会直接判为完成；真实后台也明确关闭了续写能力。

现在要求正文、状态块和最终隐藏标记 <SR_DONE> 全部完整。服务器流式拦截状态块与结束标记，普通流结束和 finish_reason 均不能作为完成依据。截断或已开始响应后的传输中断会继续同一轮，最多追加3次模型请求，每次独立180秒超时；携带已有原始前缀及相同模型、采样、卡片、行动和骰点。已完成但不合法的状态直接拒绝，不借续写掩盖内容错误。

合成模型测试覆盖：正常结束无额外请求；正文、状态开闭标记、JSON、最终标记中间截断；状态完整但缺结束标记；标记／JSON被重新输出；SSE任意UTF-8字节分片与非流式JSON；传输断线；首次计时器超时后续写使用新信号；第三次成功与三次均失败；续写连接失败的预算；主动停止；手动续写和至少8字符的精确边界重复去除。最终标记与状态内容不进入公开正文分片。HTTP集成测试验证首次加最多3次共4次调用，只有一次 done，失败无状态提交，非法手动续写参数在上游调用前拒绝。

工作区测试验证续写进度、三次失败时正文持续保存且状态不变、不生成事件记忆／建议／摘要；手动继续复用当前稿件ID，只追加新文字，保留原骰点且不增加回合，完成后只写一次记忆；主动停止后到达的结果不能提交。网关测试验证进度不是完成事件，以及最终失败提示可识别。界面提供进度、停止、继续续写，并说明最多3次额外请求可能计费。

最终验证：72项前端／工作区／SSR组件测试及61项服务器／模型适配测试，共133项通过（服务器核心整套60项通过后，新增的独立超时场景随16项续写套件通过）；类型检查和生产构建通过。预览按正常网络权限启动，仍仅监听127.0.0.1，health确认v0.11.0、bootstrap确认continue:true、首页HTTP200，地址 http://127.0.0.1:5173/。

未读取用户真实Key，未调用真实付费模型。未绕过此前浏览器读取策略限制；视觉与真实供应商遵守断点续写指令的质量仍需用户试用确认。结束标记验证的是协议完整性，不能证明模型在语义上没有漏写剧情；重复去除只处理精确边界，不推断改写后的语义重复。
