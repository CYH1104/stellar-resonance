# 剧情显示与错误原文记录

顶栏 14 为“格式错误文本”，15 为“自动隐藏楼层”。自动隐藏默认开启，只限制页面 DOM：剧情最多显示十轮，论坛最多显示十条。滚至边缘继续滚动、触摸滑动，或点击边缘文字即可换页。关闭自动隐藏可恢复全部剧情楼层。所有完整存档、论坛、记忆仍保存在原浏览器数据库中，模型历史检索和导出不受显示窗口影响。

论坛按最新在前排列。新消息出现时回到顶部；“最新”回到最新一页，“最早”切到最旧一页。剧情浏览旧页时发送新行动会回到最新十楼；论坛来源链接可以定位到尚未挂载的剧情楼层。

生成任务由工作区持有，切换阅读页面或返回学院不会停止生成。新建、删除、切换存档及修改正在使用的剧情仍受原保护；需要结束生成时使用停止按钮。关闭或刷新浏览器页面会中止当前网络请求，已收到的内容按原机制保留。

格式错误原文仅在当前客户端明确请求时返回，保存在独立、按账号隔离的 `academy-format-errors-v1` IndexedDB 中，最多一百条，最新在前。该记录不包含请求提示词、Key 或独立 reasoning 字段；正文中的思考标签也会被过滤。查看时以纯文本展示，只挂载选中记录的长文本。清空错误记录不会删除存档或聊天。它不纳入存档备份，已有数据库和备份格式不变。

多行输入自动增高，到视口约 30% 后在框内滚动。模型输出的字面换行会按段落显示，历史 USER/CHAR 身份包装不会显示在正文中；代码和 Windows 路径保持原义。世界书条目支持从 ≡ 把手拖动排序；管理页仍保留原来的插入顺序数字，列表排列与注入优先级分开。

小剧场状态补全按 slot 与 kind 匹配旧内容；新回合请求提供有限的上一轮小剧场摘录并要求生成新片段，避免模型因没有参考而重复旧内容。此参考不修改既有剧情、论坛或小剧场记录。
