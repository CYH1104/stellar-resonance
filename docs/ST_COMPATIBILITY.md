# SillyTavern 兼容范围

目标是兼容实际需要的字段和行为，而不是内置完整 SillyTavern 运行环境。目标版本与真实导入样例待作者确认。

| 对象 | 第一阶段 | 后续与限制 |
| --- | --- | --- |
| 角色卡 | V2/V3 常用字段，JSON 和 PNG 元数据，规范化与校验 | 未支持字段形成报告，不承诺完整规格覆盖 |
| 世界书 | 条目、关键词、启用状态、常驻与最小注入属性 | 递归、概率、分组等高级规则按样例逐项评估 |
| 触发 | 关键词、扫描深度、优先级、预算 | 先过可见性与授权；排序可复现 |
| 预设 | 基础系统/角色/玩家位置与允许的模型参数 | Alpha 扩展顺序、占位符、注入位置 |
| 正则 | 受约束文本变换 | 无 eval、任意 JS、无限耗时执行 |
| 变量 | 项目 Schema 与受校验更新 | MVU 协议另行评估映射 |
| 酒馆助手等插件 | 不在 MVP 自动执行 | Beta 出支持矩阵，不能直接承诺运行脚本 |

作者角色和世界书只通过作者入口导入；玩家人设与玩家自定义内容不能覆盖作者私有规则。未知格式、损坏数据、超限内容都应返回明确兼容报告。测试使用虚构世界书与角色卡。
